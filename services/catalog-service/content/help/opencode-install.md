# Установка OpenCode с площадки Нейроцентра

## Единая установка окружения проекта

На [странице начала работы](/start) нажмите «Установить OpenCode». Один мастер проведёт через OpenCode и мост, подключение компьютера, выбор проекта и папки, агентов, модель, скиллы, плагины и MCP. Администратор может отключить новые общие действия, сохраняя состояние и восстановление в этом же мастере.

Общую команду нужно выполнить в терминале нужного компьютера. Она сначала получает оба установщика с этой площадки, затем устанавливает OpenCode и мост. Браузер ничего не запускает сам. При отказе первого этапа мост не устанавливается; при отказе второго установленный OpenCode сохраняется. Для продолжения только моста откройте [подключение компьютера](/start?setup=1&step=1). Этот же этап доступен через «Помощь» → «Открыть подключение моста» в мастере.

Дальнейшая настройка выполняется в этом же сценарии:

1. Подтвердите подключение и выберите компьютер.
2. Выберите доступный проект, общую папку и точную локальную папку проекта.
3. В «Агенты и модель» назначьте агентов, настройте модель и примените настройки. В «Скиллы, плагины и MCP» установите назначенные проекту версии. Планы установки, одобрения и локальные параметры сохраняют обычные правила доступа.
4. Откройте «Проверка»: сверка файлов, настройка и диагностика запуска показываются отдельно для каждого инструмента. Копирование команды, наличие моста и установка файлов сами по себе не подтверждают ответ модели.

Выбранный проект и этап сохраняются в адресе страницы. При ошибке обновите состояние и продолжите нужный шаг. Отсутствующий pin назначения или неподтверждённая папка блокируют установку; весь общий каталог автоматически не устанавливается. Ручная конфигурация и ключи сохраняются действующими установщиками.

Открытый шаг и готовность окружения показаны отдельно: переход к «Проверке» не означает завершения предыдущих действий. До подключения моста подробный ход установки виден в терминале. После подключения обновляются состояние компьютера, папки и квитанции инструментов. Версия пользовательского CLI пока не измеряется сайтом автоматически; проверьте её командой ниже. Мастер доступен клавиатурой, явный переход открывает и фокусирует выбранный шаг.

## Установка, проверка и ручное восстановление

### OpenCode

Откройте [шаг установки основного мастера](/start?setup=1&step=0), скопируйте общую команду для своего компьютера и выполните её в терминале. Она устанавливает OpenCode и мост. Для macOS, Linux, WSL и Git Bash используется Bash, для Windows — PowerShell. Адрес площадки подставляется в интерфейсе: менять его вручную не нужно.

Установщик выбирает пакет по ОС и архитектуре; архивы скачиваются с Нейроцентра. Глобальная установка OpenCode через npm не требуется. Существующая конфигурация и ключи сохраняются.

Предусмотрены пакеты для macOS Intel/Apple Silicon, Linux x64/ARM64 (glibc и musl), Windows x64/ARM64. WSL использует Linux-пакет. Наличие пакета на вашей площадке и совместимость с системой проверяются отдельно; перечень целей не подтверждает нативную приёмку каждой ОС.

После установки откройте новый терминал и проверьте:

```sh
opencode --version
```

Если пакет отсутствует, передайте администратору название архива из сообщения. Установщик не переключается на внешний registry.

### Локальный архив

Если администратор передал подходящий платформенный архив и сохранённый Bash-скрипт:

```sh
bash install_opencode.sh --binary ./opencode-package.tgz
```

Архив должен соответствовать системе компьютера. Скрипт проверяет запуск бинарника до замены действующей версии.

## Провайдер моделей

Если модель доступна в каталоге Нейроцентра, откройте её карточку и выберите «Настроить в OpenCode». Подробности — в статье [«Модели»](/help/models).

Для самостоятельного подключения доступного вам провайдера получите ключ, если он требуется, и запустите:

```sh
opencode auth login
```

Следуйте подсказкам выбранного провайдера. При необходимости отдельно укажите его URL и идентификаторы моделей в конфигурации OpenCode. Не добавляйте личные ключи в репозиторий. Наличие установленного бинарника не подтверждает доступность модели.

По умолчанию конфигурация находится в `~/.config/opencode`, авторизация — в `~/.local/share/opencode`. Переменные `XDG_CONFIG_HOME` и `XDG_DATA_HOME` учитываются. В Windows базовый каталог — домашняя папка пользователя. Подробности: [провайдеры OpenCode](https://opencode.ai/docs/providers/).

## Компьютер и папка проекта

Перейдите к [шагу подключения компьютера](/start?setup=1&step=1) и подтвердите подключение моста. Если его установка прервалась, на этом же шаге доступно повторное подключение. Установщик дополняет JSON/JSONC-конфигурацию, сохраняя другие MCP, плагины и комментарии.

Свяжите локальную папку с серверным проектом по постоянному ID. Названия папок и их расположение могут различаться на разных компьютерах. Не создавайте второй серверный проект только из-за другого локального пути.

Администратор проекта выбирает доступный набор инструментов, затем участник устанавливает разрешённые версии через мост в связанную папку. Кнопка «Установить через мост» у администратора также добавляет отсутствующий инструмент в каталог проекта. Простое добавление в каталог не запускает локальную установку.

## Запуск из папки проекта

```sh
cd ~/projects/example-project
opencode
```

После добавления MCP или плагинов перезапустите OpenCode. Для навигации и диагностики кода откройте статью [«Работа с кодом: LSP»](/help/opencode-lsp).

Для OpenCodeRAG нужна модель эмбеддингов и подготовленный индекс. Настройка и следующий шаг описаны в статье [«Модели»](/help/models). Подключение чат-модели в OpenCode не настраивает эмбеддинги автоматически.

OpenCode — отдельный публичный проект: [документация](https://opencode.ai/docs/).
