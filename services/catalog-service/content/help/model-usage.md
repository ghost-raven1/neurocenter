# Использование и лимиты моделей

Откройте [Использование моделей](/model-usage), чтобы посмотреть операции и обращения к API за день, неделю или месяц.

Главный администратор видит всех пользователей и серверные задания. Администратор проекта видит всех пользователей в проектах, которыми управляет. Разработчик видит свои операции в доступных проектах и личные обращения.

## Как разобраться в расходе

Выберите пользователя, проект или модель. Дополнительные фильтры выбирают агента, назначение, статус и тип API. Вкладки ниже показывают итоги по пользователям, проектам, моделям и агентам. Итоги охватывают весь период; кнопка «Показать ещё» раскрывает историю операций.

Операция может завершиться до отправки запроса: например, если отменено ожидание лимита. Поэтому число операций и число обращений к API показаны отдельно. Время ожидания лимита также отделено от времени ответа API.

«Нет данных» означает, что счётчик отсутствует. Это не ноль. Для старых записей новые показатели не восстанавливаются задним числом. Стоимость запросов не рассчитывается.

## Как настроить ограничение

Главный администратор открывает карточку модели и раздел **Лимит запросов**. По умолчанию разрешено **5 запросов за 5 секунд**. Ограничение общее для пользователей и агентов этой модели; другие модели имеют собственный лимит.

Можно задать число запросов и период или отключить ограничение модели. Флаг **Лимиты запросов моделей** выключает контроль целиком, сохраняя настройки. При одновременном редактировании интерфейс предложит сравнить изменения и сохранит ваш ввод.

Если квота занята, запрос ожидает до 30 секунд. Затем можно повторить его вручную или попросить администратора увеличить лимит. Отмена ожидания не отправляет запрос модели. Неопределённый результат уже отправленного обращения автоматически не повторяется.

Учитываются обращения, которые выполняет сервер Нейроцентра, включая chat, embedding и проверку подключения. Прямые вызовы внешнего API из других программ имеют собственные ограничения.
