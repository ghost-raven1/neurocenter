# Как редактировать Помощь

Статьи хранятся в файлах Markdown с расширением `.md`. Изменение исходного файла становится доступно при следующем открытии или обновлении статьи, без пересборки интерфейса.

## Через интерфейс

Главный администратор может создать статью, изменить Markdown, загрузить `.md`, посмотреть предварительный результат и сохранить изменения. Первый заголовок `#` используется как название статьи. Ссылки на другие статьи можно задавать как `/help/имя-статьи` с латинским идентификатором.

Если статью успел изменить другой редактор, сохранение остановится с конфликтом. Сначала прочитайте актуальную версию и сопоставьте её со своим черновиком. Несохранённый текст не должен теряться при ошибке.

## Файлы на сервере

По умолчанию статьи находятся в `content/help` пакета `catalog-service`. Каталог можно задать переменной `HELP_CONTENT_DIR`; в контейнерной поставке он сохраняется в отдельном томе. Редактируйте только обычные UTF-8 файлы `.md`, без символических ссылок.

Для разметки доступны заголовки, списки, таблицы, ссылки и блоки кода. HTML в статьях не исполняется; внешние изображения автоматически не загружаются.

Комментарии к статье хранятся отдельно: изменение её текста не удаляет обсуждение.
