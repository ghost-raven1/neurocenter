# Подключение моделей

В [каталоге моделей](/store?tab=models) можно настроить модель на сервере или подключить внешний OpenAI-совместимый API. Настройку общего каталога выполняет главный администратор.

## Внешний API

Добавьте модель, выберите внешний API и задайте адрес, точный идентификатор модели и необходимые учётные данные через форму настройки. Затем проверьте соединение. Название карточки помогает людям, а идентификатор модели должен совпадать с тем, который принимает провайдер.

Не публикуйте ключи в описании, статье или комментариях. Используйте предназначенные для секретов поля.

В карточке модели главный администратор также задаёт лимит обращений: по умолчанию 5 запросов за 5 секунд. Расход по пользователям и агентам показан в разделе [Использование моделей](/model-usage). Подробнее — [использование и лимиты](/help/model-usage).

## Модель в проекте

Выберите проект и добавьте в него модель. Для OpenCode используйте действие настройки в карточке модели, если оно доступно. Серверная модель и локальный провайдер OpenCode могут иметь разные требования к доступности сети.

## База знаний

Для поиска по смыслу нужна модель эмбеддингов. Её размерность должна соответствовать индексу проекта. При смене модели следуйте подготовке нового индекса в разделе «База знаний» проекта; не подменяйте рабочий индекс вручную.

Статус «Готова» в карточке относится к модели. Сам по себе он не устанавливает OpenCodeRAG и не создаёт индекс файлов.

1. Подключите компьютер и свяжите папку проекта. Если мост уже на связи, проверьте именно привязку папки в проекте.
2. В каталоге проекта установите OpenCodeRAG — MCP или плагин. После успешной установки автоматически запускается сверка файлов. Её ход виден в «Операциях». Для уже установленной версии действие «Проверить файлы» доступно в блоке «На этом компьютере».
3. В каталоге моделей выберите «Сервер и OpenCodeRAG на компьютере», компьютер и проверенную установку. Добавьте модель эмбеддингов в проект и подтвердите предложенный план подключения. Мастер перестроит локальный индекс отдельно от прежнего и синхронизирует его с сервером.
4. Дождитесь результата проверки индекса и синхронизации. Перезапустите открытую сессию OpenCode, чтобы она использовала новое подключение.

Режим «Только серверная база знаний» изменяет серверную базу; он не индексирует файлы на компьютере. Если установка недоступна, используйте показанное действие для установки, привязки папки или обновления моста. Если проверка файлов завершилась ошибкой, откройте её результат в «Операциях» и исправьте указанную причину.

Runtime OpenCodeRAG хранится в приватном кэше моста. В `opencode.json` связанной папки записывается подключение к нему; отсутствие исходников плагина в папке проекта само по себе не означает ошибку установки.
