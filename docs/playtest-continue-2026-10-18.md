# Продолжение полировки и плейтест — 18 октября 2026

Закрыты четыре замечания P2 предыдущего аудита и найденные при повторных сценариях тупики восстановления и упаковки. Изменения проверяются на локальном стенде, в изолированных папках и тестовых БД. Промышленный допуск остаётся **NO-GO** до внешней приёмки.

## Изменения

| Сценарий | Исправление |
| --- | --- |
| Start предлагал два перехода к одной привязке | Оставлено одно действие выбора папки; отдельный переход к инструментам сохранён. |
| Пустые установки занимали слишком много места | Убрана большая иллюстрация; высота карточки уменьшилась с 386,5 до 194,5 px на desktop и с 430,5 до 216,5 px на mobile. |
| Прямой `/operations` открывал 404 | Адрес открывает существующую очередь; reload, остальные query-параметры, hash и возврат назад сохраняются. |
| Панели операций не имели доступного имени | Именован фактический `role=dialog`; Escape закрывает вложенные подробности по очереди. Фокус возвращается к кнопке и после быстрого Escape до конца анимации. |
| Повреждённый кэш блокировал повтор и восстановление | Явный preview и подтверждение разрешают повторную загрузку одобренного комплекта. SHA, размеры, лимиты и права проверяются до применения; прежние байты сохраняются в учитываемом карантине. Обычная сверка сама кэш не изменяет. |
| Обновление preview сбрасывало согласие | Согласие закреплено за точными job/plan/revision/digest. Повторный GET того же плана сохраняет checkbox; новый план требует нового подтверждения. |
| Современный npm-пакет отклонялся до сборки | Поддержаны корневые conditional exports, module и TSX entrypoint; types и subpath exports не подменяют файл запуска. |
| Через 45 секунд неизвестный POST терял UUID | Неопределённый исход сохраняет исходный ключ, в том числе при HTTP 400 на повторе и смене формы. Поздний ответ возвращает прогресс той же сборки; автоматического повторного POST нет. |
| Недоступный localStorage позволял новый UUID | В пределах открытой страницы неизвестный ключ сохраняется в памяти. Reload при полностью недоступном хранилище этой проверкой не покрыт. |
| Кнопка предупреждения сжимала мобильный текст | CTA перенесён под описание. На 390 px ширина текста выросла с 0 до 254 px, высота Alert уменьшилась с 4109 до 262 px. На 320 px устранён конфликт специфичности с Ant Design: текст кнопки переносится, её client/scroll width совпадают (182 px). |
| Зависший HTTP-запрос удерживал форму | У запросов упаковки отдельные пределы: подготовка/создание 90 с, чтение состояния 10 с, общий поиск исходного запроса 45 с. Отмена доходит до transport, UUID остаётся для явного повтора. |

Короткие feature-helpers вынесены для доступных Drawer, проверки разрешённого runtime и восстановления запроса сборки; preview восстановления переиспользуется. Существующая архитектура React/Ant Design сохранена. Четыре ранее отмеченных больших модуля остаются кандидатами на отдельное разделение по features; массовое перемещение к этим исправлениям не добавлялось.

## Браузерный плейтест

Основные пути пройдены на **1440×1000** и **390×844**. Реальные чтения и навигация отделены от перехваченных изменяющих запросов. Привязки папок, установки, индексирование и синхронизация пользовательских проектов не запускались.

1. Start → проекты: одно действие привязки, отдельный переход к инструментам.
2. Проект → инструменты: компактный пустой список и конкретное действие для неподключённой папки.
3. Инструменты → RAG → помощь → каталог: выбранный проект сохраняется, отступы и ширина проверены.
4. Legacy URL операций → reload → закрытие → Back: очередь и адрес согласованы.
5. Клавиатура: имена двух диалогов, последовательный Escape и возврат фокуса; четыре варианта обычного/быстрого закрытия на двух ширинах.
6. Fixture восстановления кэша: предупреждение, disabled до согласия, сохранение checkbox при polling, новое согласие для нового плана и один apply с точным digest.
7. Fixture потерянного POST: unknown → reload → явный retry/HTTP 400 → поздний ответ 37% → повторный reload. Во всех запросах один UUID.
8. Mobile warning и отказ хранилища: кнопка под текстом; изменение формы при SecurityError не создаёт новый UUID в той же странице. Дополнительно проверены текст кнопки и ширина документа на 320 px.

Подробные шаги, свежие скриншоты и измерения: [основной путь](../output/playwright/neurocenter-playtest-continue/frontend-playtest.md), [потерянный ответ](../output/playwright/neurocenter-playtest-continue/pending-browser.md), [responsive и хранилище](../output/playwright/neurocenter-playtest-continue/pending-responsive-recheck.md).

Отдельно прошли **3/3 браузерных группы с зависшими запросами**: metadata освобождает подготовку после 90 с; при зависшем POST поиск доступен после 45 с, а повтор — после завершения 90-секундного ожидания POST; зависший lookup освобождает форму после общего 45-секундного deadline. Проверены реальные enabled/disabled кнопок, отсутствие loading и прежний UUID явного повтора. [Таймлайн, скриншоты и границы виртуального времени](../output/playwright/neurocenter-playtest-continue/pending-hangs-browser.md).
