- Все 15 файлов скачаны по публичным HTTPS-ссылкам без авторизации; размер и SHA-256 совпадают с опубликованными значениями.
- Проверки репозитория ассетов: 93/93, пропусков нет.

На втором шаге `scripts/dev.sh up` выберите нужные позиции из закреплённой описи. Загрузка подготавливает файлы поставки. Назначение инструмента проекту, установка в связанную папку, выбор embedding-модели и индексация остаются отдельными действиями интерфейса; публикация архива сама по себе их не подтверждает.
