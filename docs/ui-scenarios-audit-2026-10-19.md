# Сценарии через интерфейс — 19 октября 2026

Проверено **21 сценарий** в настоящем браузере на `localhost:5173`. Действия выполнялись через видимые элементы: переходы, ввод, клавиатуру, модальные окна и системный выбор файла. HTTP-ответы не подменялись. Три воспроизведённых дефекта исправлены и повторно пройдены через UI.

Это продолжение [A15–A17](bridge-recovery-audit-2026-10-19.md). Установленный рабочий мост оставался 0.9.4, исходники и автономная поставка — 0.9.7. Этот проход изменяет только frontend.

## Исправления

| ID | Воспроизведение | Результат |
| --- | --- | --- |
| A18 | Ручное добавление → скилл → неверный идентификатор → ошибка → переключение на MCP. Красная ошибка скилла оставалась при скрытом поле | Изменение черновика отзывает прежнюю общую ошибку. Поля, файлы и незавершённый ввод сохраняются |
| A19 | Плагин → выбрать index.js точкой входа → удалить файл. Список файлов пуст, но точка входа выглядела выбранной | Удаление или переименование выбранного файла очищает исчезнувший entrypoint. Другие файлы и их содержимое сохраняются; серверная валидация не ослаблена |
| A20 | В списке проектов установлен фильтр проекта B → через «Базы знаний» открыт A → «Связать папку проекта». Возврат показывал только B, целевой A терялся | Ссылка содержит канонический ID в bind. Существующий мастер открывается для A независимо от фильтра. Закрытие удаляет только bind; поиск, страница и выбранный компьютер сохраняются |

Привязка выполняет только чтение выбранного проекта до явного действия пользователя в мастере. Ответ прежнего запроса, закрытие, смена проекта или auth-scope не открывают чужой мастер. Ошибка отсутствующего проекта имеет пояснение, повтор и закрытие.

## Код и ограничения

Frontend: **1408/1408 тестов**, **130 файлов**, без пропусков. TypeScript и production build успешны. Новые тесты сначала воспроизвели дефекты на прежнем коде. Независимое review привязки проверило владельца, поздние GET, закрытие, смену проекта/устройства и отсутствие автоматических заданий.

Сохраняются прежнее предупреждение Vite об общем chunk около 834 КБ и предупреждение React об Ant Design 4 Table.defaultProps. Исключений приложения в просмотренных браузерных логах нет; несовместимость будущего React этим проходом не устраняется.

Создание рабочих проектов/пользователей, изменение прав, сохранение настроек, публикация инструментов, запуск хостинга и задания моста не выполнялись. Реальные чтения метаданных и временный разбор тестовых архивов выполнены через UI. Поэтому успешная новая установка, передача индекса и восстановление рабочих данных этим проходом не принимаются. На выбранном компьютере целевой проект ещё не связан; текущая версия моста также ограничивает запуск интерфейса RAG.

Локальные снимки до/после, тестовые архивы и scenarios.json находятся в `output/playwright/ui-scenarios-2026-10-19/`; они не включены в публичную репу. Общие [P0-критерии](implementation-readiness.md) остаются открытыми.
