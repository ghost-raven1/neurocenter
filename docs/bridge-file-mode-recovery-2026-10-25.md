# Права файлов при откате установки: 25 октября 2026

Если обновление удаляло исполняемый файл, а следующая запись завершалась
ошибкой, откат возвращал содержимое с режимом `0600`. Право на запуск терялось.

Теперь журнал сохраняет исходные права `0000..0777`, полученные из того же
проверенного файлового дескриптора, что и содержимое. `commitChanges` собирает
эти сведения самостоятельно, включая вызовы без `InstallationPlan`, до
кодирования журнала и расчёта необходимого места. Заявленный вызывающим кодом
режим должен совпадать с наблюдаемым. Проверки fingerprint до фиксации сохранены.

При откате удалённого файла применяется сохранённый режим. Существующий файл
сохраняет текущие права, включая ручной `chmod`. Журналы прежнего формата читаются;
если исходный режим неизвестен, отсутствующий файл восстанавливается с `0600`.

## Проверки

- До исправления отдельный сценарий воспроизвёл потерю режима: байты и архив
  `rolled-back` восстановлены, последняя проверка получила `0600` вместо `0751`.
  Результат — 1 FAIL и 18 пропусков по фильтру, сохранён как причинный RED.
- После исправления пять полных наборов прошли: **68 passed, 0 failed, 0 skipped**.
  Проверены `atomic-file`, `read-bounded`, `installation-journal`,
  `installation-files`, `installation-files-safety`.
- В сценариях используются реальные временные файлы и управляемый `ENOSPC`
  следующей публикации. Проверены прямой вызов, чтение сохранённого `prepared`,
  старый журнал, ручной `chmod`, некорректный и не совпадающий с файлом режим.
- Проверка типов production-исходников моста прошла на Node 24.22.0 и
  TypeScript 5.9.3 с `--noEmit --incremental false`.

установку свежего архива, аварийный перезапуск реального процесса, проверку Windows
или применение в main. Владельцы, ACL и расширенные атрибуты этим срезом не покрыты.
Общий регресс моста и перенос оставшегося RAG UI остаются отдельной работой.
