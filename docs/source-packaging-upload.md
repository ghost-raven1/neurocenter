# Готовая поставка MCP как источник упаковки

Упаковщик принимает готовый ZIP, TAR.GZ/TGZ или исполняемый файл размером от 1 байта до 256 МиБ. Бинарные данные передаются отдельным потоком через API gateway. Они не помещаются в JSON, `files`, localStorage или IndexedDB.

Метаданные проверяют содержимое без запуска присланных программ. Несколько исполняемых файлов требуют явного выбора; набор платформ относится к выбранной программе. Python/JVM/.NET требуют готового приложения и подходящего встроенного runtime. Обычная CLI не превращается в MCP-сервер: проверка протокола установленной программы выполняется отдельно от определения структуры поставки.

## API

Все операции привязаны к авторизованному главному администратору. Внутренний сервис принимает удостоверенного gateway-владельца, а не произвольный запрос браузера напрямую.

| Запрос | Результат |
| --- | --- |
| `POST /api/tool-builds/uploads` | Создать запрос `{requestKey, name, sha256, bytes}`. `requestKey` — UUID v4, неизменяемый для повторов той же операции. |
| `GET /api/tool-builds/uploads/requests/:requestKey` | Восстановить результат после неизвестного ответа создания или передачи. |
| `GET /api/tool-builds/uploads/:id` | Прочитать состояние по непрозрачному серверному UUID. |
| `PUT /api/tool-builds/uploads/:id/content` | Передать `application/octet-stream`. Проверяются фактический размер и SHA-256 до состояния `READY`. |
| `DELETE /api/tool-builds/uploads/requests/:requestKey` | Отменить известный или ещё не наблюдавшийся запрос. Tombstone запрещает позднее создание под тем же UUID. |
| `DELETE /api/tool-builds/uploads/:id` | Отменить незакреплённую загрузку. Источник, уже сохранённый в истории сборки, защищён ответом 409. |

Создание и передача зависят от флага `tool_builds`. Чтение и отмена доступны и после его отключения. Сервер не возвращает пути к файлам.

Готовая загрузка передаётся в обычный запрос сборки:

```json
{
  "type": "upload",
  "uploadId": "7428c85e-c645-4f05-b610-6f0029867f93",
  "sha256": "<64 hex symbols>",
  "bytes": 123456,
  "entrypoint": "bin/server"
}
```

Это управляющая ссылка на проверенный источник. Выход использует общий контракт ассета: `source.type = archive` и native delivery 5. Исходные байты сохраняются без преобразования, включая проверяемые SHA и размер.

## Состояние и восстановление

Клиент сначала проверяет SHA-256, затем сохраняет небольшой точный запрос в IndexedDB, и только после подтверждённой записи вызывает API. Повтор использует тот же UUID и те же байты. До создания сборки источник должен быть полностью сохранён сервером.

Отмена ждёт незавершённую запись IndexedDB, отменяет её точный UUID и очищает запись через CAS. Неизвестный ответ отмены сохраняет запрос для повторной проверки. Смена пользователя/роли/проекта и возврат A → B → A запрещают устаревшим операциям изменять новую форму или начинать передачу.

После сохранения полного тела на диск потеря соединения не прерывает определение метаданных: результат можно получить по UUID. Явная отмена, отзыв прав и серверный срок операции продолжают останавливать обработку. Отзыв и последующая выдача прав не оживляют старый источник.

Незакреплённые источники живут 24 часа и очищаются после истечения срока или отзыва прав. История сборок защищает используемые исходники от очистки. Кнопка «Выбрать другую поставку» забывает только состояние формы; сохранённые байты исторической сборки остаются доступны.

Сервер ограничивает одновременную передачу тремя потоками на экземпляр, оставляя соединения БД для чтения и отмены. Перед передачей резервируется место для исходника и ограниченной распаковки. Traversal, ссылки, коллизии регистра/Unicode, повреждённые архивы, неподтверждённые runtime и неподходящие платформы отклоняются до успешной сборки.

## Проверки

Автоматические проверки включают настоящие HTTP-потоки (включая фактическое превышение 256 МиБ), PostgreSQL с отдельными тестовыми схемами, файловую систему, архивы и общий builder. Проверки browser UI и фактического MCP-протокола на мосте должны учитываться отдельно от этих результатов.
