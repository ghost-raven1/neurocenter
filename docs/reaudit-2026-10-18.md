## Границы упаковки и адаптеров

В интерфейсе: **Каталог → Упаковать инструмент → npm / GitHub / файлы → Упаковать и добавить**. Общий builder используется и API, и операторским CLI. npm-версия либо полный commit закрепляются до очереди; повтор не создаёт новую публикацию.

Python, Java, .NET, Go, Rust и native используют тот же delivery/descriptor/SHA и установку через мост. Для non-JS репозитория поддерживается `neurocenter.tool.json` с готовыми платформенными assets; для Python/Java/.NET поставляется самостоятельный runtime. Компиляторы и пакетные менеджеры на компьютере пользователя не требуются. Произвольные исходники Maven/Gradle/Go/Rust/.NET/Python автоматически не компилируются: готовый manifest и самодостаточная поставка — обязательная граница текущего механизма. Приватные Git/SSH также не поддерживаются. [Рецепты и примеры](../scripts/catalog-plugins/README.md).

Синтетическая поставка проверена для восьми targets; SHA восьми upstream OpenCode архивов подтверждены. Это проверка формата/целостности. Нативная приёмка новой версии на остальных семи платформах отсутствует.

## Читаемость и следующий рефакторинг

Транзакционный переход device job вынесен в небольшой feature-helper; выбор runtime и план проверок вынесены в `scripts/workspace`. Соседние модули не переписывались без связи с дефектами.

Четыре существующих файла остаются больше 500 строк: общие frontend API interfaces (566), catalog controller (835), service (831), DB (736). Рекомендуемый следующий срез — вынести API-типы в соответствующие features, затем разделить catalog по проектам, версиям и установкам с сохранением транзакционных границ. Массовое перемещение одновременно с исправлением очереди затруднило бы проверку поведения. [Опись](../output/playwright/neurocenter-reaudit/oversized-modules.json).

Неблокирующие P2 интерфейса остались в отчёте: повторяющиеся переходы к привязке проекта, слишком высокий пустой блок установок, старый прямой `/operations` с 404 и доступное имя drawer-диалогов. Полный keyboard/screen-reader/WCAG-аудит не проводился. Они не обозначены исправленными или принятыми production-проверкой.

В checkout отсутствует `.git`; история веток, синхронизация с remote и публикация изменений не подтверждены. [Машинный итог и свидетельства](../output/playwright/neurocenter-reaudit/report.json).
