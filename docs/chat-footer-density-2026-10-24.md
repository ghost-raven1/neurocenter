# Чат: компактные настройки и история синхронизации

## Исправленное поведение

Контекст участников, источники исследования и выбор документов открываются в одной всплывающей панели над полем сообщения. Развёрнутые сведения имеют собственную прокрутку и не увеличивают нижнюю часть чата. Открыта только одна панель; переход между панелями не меняет черновик, источники и согласие на исследование.

Согласие на исследование и причины блокировки сообщения остаются видимыми. Первый Escape в открытом выборе MCP закрывает список, следующий закрывает панель и возвращает фокус. Панель находится внутри окна чата, включая клавиатурный путь и StrictMode.

При высоте окна до 480 px второстепенные отступы уменьшены. Поле сообщения показывает до 72 px текста с прокруткой, история сохраняет ненулевую высоту. Очень длинные предупреждения и вложения используют прокрутку основной области; содержимое не скрывается.

Историческая квитанция синхронизации RAG обозначена как запись прошлой операции и оформлена нейтрально. Она не является проверкой текущего индекса. Ссылка ведёт в настройки индекса; свежая ошибка принятой операции сохраняет оформление ошибки. История, блокировка повторного запуска и проверка прав сохранены.

## Проверка

- 103 целевых теста чата: рабочая область, исследование, события ввода, реальный Ant Design Modal/Popover/Select под StrictMode.
- 77 тестов синхронизации и доступности моста. Воспроизведение до исправления: историческая ошибка не отличалась от текущего состояния; свежий отказ проверен отдельно.
- После изменения адаптивных стилей повторены 10 затронутых проверок из набора чата; это повтор, а не дополнительные уникальные тесты.
- TypeScript и изолированная production-сборка frontend прошли. Другие сервисы для этого изменения не пересобирались при локальной проверке.

Измерения в настоящем браузере, синтетические данные без запросов к модели:

| Окно | История при закрытой/открытой панели | Поле и отправка |
| --- | --- | --- |
| 1200 × 620 | 281,6 / 281,6 px | внутри окна |
| 1200 × 440 | 165,9 / 165,9 px, включая раскрытые ограничения исследования | внутри окна |
| 390 × 640 | 269,6 / 269,6 px | внутри окна |
| 390 × 420, черновик 5 строк | 67,1 px, панель источников 6,3–237,3 px | внутри окна, весь черновик сохранён |

До исправления на 1200 × 440 раскрытие только контекста уменьшало историю с 133,4 до 90 px, а низ поля сообщения уходил на 488,5 px за окно.

Локальные квитанции: `.run/chat-tools-density-20261024/frozen-receipt.json` в рабочем дереве разработки, `.run/chat-footer-20261024/` в основном дереве. Проверены клавиатура, Escape и закрытие по внешнему клику. Screen reader, физическое мобильное устройство и весь репозиторий этой проверкой не охвачены.

## Продолжение

- Полноценный служебный чат и постоянное назначение моделей системным ролям остаются отдельными задачами.
- Для обучения требуется восстановление неизвестного результата Quirks/MCP Memory по исходному ключу после закрытия окна; нужен отдельный API чтения квитанции.
- Другая размерность эмбеддингов требует проверенной модели и переиндексации. Общего атомарного переключения сервера и всех компьютеров нет; реальная смена размерности этим UI-срезом не проверялась.
