# Контекст RAG в чатах: 25 октября 2026

## Реализованный срез

Обычный вопрос продолжает выполняться при подтверждённой недоступности
необязательной embedding-модели или поиска. Ответ не получает вымышленных
источников. Ошибочные HTTP 502/503/504 распознаются до чтения тела ответа.
Ошибки доступа, отмена, смена профиля или снимка, некорректный успешный ответ
и неподтверждённая синхронизация сохраняют свои проверки.

В контекст проходят только проверенные поля источников. Одинаковые фрагменты
объединяются с сохранением лучшей оценки; разные позиции файла сохраняются.
Контекст подбирается отдельно под окно каждого участника. При нехватке места
сокращаются необязательные источники, исходный вопрос и история сохраняются.

Выключение поиска закрывает следующий вызов, но само по себе не отбрасывает
уже полученный ответ. Явный запрос исследования проекта требует разрешённого
поиска даже при выключенном автоматическом подборе контекста.

## Оставшаяся приёмка и следующий срез

Три инфраструктурных набора — `model-chat-db`, `chat-learning-context`,
`chat-research-execution` — требуют отдельного временного PostgreSQL/S3
стенда. Проверка типов не подтверждает их выполнение. Основная БД не является
тестовым стендом. Браузер, установленный мост, архив, CI и main этим срезом
не приняты.

Автоматический RAG для системных ролей и координатора остаётся следующим
изменением: согласованный доступ к индексу проекта, не более одного поиска
на задание внутри существующего бюджета, подбор источников каждому участнику
и отображение цитат в результатах ролей и сервисном чате.

Отдельно обнаружена общая граница ModelApiAdmission: проверка после ожидания
COMMIT лимитов зависит от наличия `beforeDispatch`. Требуются причинная
проверка реального владельца лимитов и самостоятельное исправление перед
физическим вызовом провайдера. Этот дефект данным срезом не исправлен.
