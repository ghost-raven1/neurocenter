# Локальная конфигурация OpenCode — 23 октября

Добавлен [локальный редактор файлов проекта](features/project-configuration.md), открываемый из блока агентов через привязанный мост. Флаг `project_configuration`, права администратора и отдельный post-ACK permit ограничивают новое открытие, чтение, предпросмотр и запись. Содержимое файлов, diff и локальные копии не передаются сайту. Результат задания подтверждает только открытие формы.

Временные проекты проверяют snapshot-CAS, конкурирующие редакторы, отзыв прав, отключение флага, истечение сессии, закрытие во время запроса, симлинки, сохранность JSONC/неизвестных полей, защищённые агенты и подключения, приватную квитанцию установленного RAG и явный раздел AGENTS.md. Журнал записи не наследует завершённое задание открытия. Gateway разрешает только точный новый permit-маршрут.

Пройдены целевые наборы без skips: мост 23 теста (два файла), Catalog 79 (четыре файла), frontend 37 (четыре файла), Gateway 34 (один файл), bridge build fixture 4. TypeScript noEmit пройден для всех четырёх пакетов. Это выбранные наборы, а не общий процент покрытия. В отдельном браузерном временном проекте проверены AGENTS.md, форма RAG, предпросмотр, локальное применение и закрытие; desktop 1280 и mobile 390 без горизонтального переполнения, ошибок console нет. Квитанция и четыре изображения находятся в `.run/project-configuration-proof/` этой рабочей ветки.

Открыты независимое ревью, финальная объединённая сборка, проверка обычного установленного моста и OpenCode на реальных ОС, CI и production. Пользовательские папки и работающие службы не менялись. Уже существующая доставка канонических агентов сайта сохранена; редактор её не дублирует.
