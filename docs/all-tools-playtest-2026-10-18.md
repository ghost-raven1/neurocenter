# Проверка всех плагинов и MCP каталога

Проверен весь текущий набор из **9 исполняемых инструментов: 5 MCP и 4 плагина**. Исходный состав, версии и SHA взяты из живого локального каталога: [inventory-before.json](../output/playwright/neurocenter-all-tools/inventory-before.json). Машинный итог: [report.json](../output/playwright/neurocenter-all-tools/report.json). Это граница проверки; сторонние расширения за пределами этого каталога сюда не входят.

## Что исправлено

- «Контекст проекта» больше не роняет hook OpenCode при допустимом JSON `package.json = null`, массиве или некорректном типе `scripts`. Регрессионные тесты проверяют также обычный файл и повреждённый JSON. Новая ревизия — `1.0.1-pack.1`.
- OpenCodeRAG больше не выдаёт отказ провайдера эмбеддингов за успешный поиск без результатов. HTTP 401/503 возвращаются как MCP `isError`, включая `find_usages`; незавершённое индексирование возвращает ошибку со статистикой. Настоящая пустая выдача остаётся успешной. Ошибки очищаются от тела ответа и секретов, дополнительный запрос к модели не выполняется. Финальная ревизия — `2.4.4-mcp.pack.3`.
- Независимый review воспроизвёл дополнительную запись исходной ошибки внутри upstream Ollama до внешнего перехвата. Внутренний журнал только этого провайдера отключён штатной настройкой фабрики; журнал pipeline сохраняется и получает очищенную ошибку. [Красное свидетельство на фиктивном токене](../output/playwright/neurocenter-all-tools/review/ollama-raw-log-red.json), [независимая зелёная проверка текущего createRagContext](../output/playwright/neurocenter-all-tools/review/ollama-raw-log-green.json). Проверки MCP-ответа и stderr сами по себе не подтверждали безопасность файлов журнала; промежуточный кандидат `pack.2` сохранён как свидетельство и не опубликован.
- `provenance.recipePath` теперь указывает на сохранённый `recipe.json` относительно provenance. Ссылка остаётся верной после переноса комплекта; SHA нормализованного рецепта сохранён. Прежний виртуальный путь мог ссылаться на несуществующий файл.
- Проектный скилл OpenCodeRAG согласован с пятью инструментами нашего MCP. Убраны обещание готового индекса и обращения к отсутствующим image/quirks tools; добавлены установка через мост, локальный мастер, проверка состояния и явное индексирование. Штатный API обновил версию 1 → 2 с `expectedVersion: 1`; предыдущая версия и метаданные сохранены. [Свидетельство CAS](../output/playwright/neurocenter-all-tools/catalog-ui/skill-update-result.txt).

## Оставшиеся ограничения

- **Fetch upstream:** HTML/неподдерживаемый XML вместо captions с HTTP 200 может дать успешный ответ только с заголовком языка. Это воспроизведённый дефект пустых субтитров, не зелёная проверка результата. Markdown сохраняет текст `script/style`; параметр proxy рассчитан на Bun и игнорируется Node. Положительные сетевые сценарии использовали явно помеченный локальный DNS/fetch harness; реальный YouTube и публичный интернет не подтверждены. [Transcript](../output/playwright/neurocenter-all-tools/mcp/fetch-transcript.json).
- **snip:** в одном параллельном прогоне зафиксирован таймаут начального hook probe в 2 секунды. Два повторных полных запуска прошли; отдельное свидетельство сбоя сохранено в `plugins-second-timeout.json`. Устойчивость при высокой нагрузке не объявляется подтверждённой.
- RAG предоставляет поиск по индексу и WASM-структуру, а не LSP. Индексы и локальные настройки пользовательских проектов этим тестом не создавались.
- Иностранные платформенные архивы можно проверить и переупаковать на Mac, но нативный запуск Windows/Linux, установщики и требования защит ОС требуют отдельных хостов. Этот проход их не заменяет.
- Реальный Blitz, независимое S3 и восстановление на другом хосте, промышленные RPO/RTO, нагрузка и наблюдаемость остаются отдельными P0-проверками.
- В checkout отсутствует `.git`: коммит, push и сверка удалённой ветки невозможны в этом каталоге.

Настоящие профили OpenCode, установленный мост, привязки папок и локальные рабочие проекты пользователя не менялись. Все тестовые процессы и auth-сессии принадлежат этому прогону; завершение и отзыв отмечены в свидетельствах.
