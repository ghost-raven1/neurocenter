# Контракт ассетов в базовой поставке

Root, Catalog и сборка Gateway используют локальный пакет `vendor/asset-contract`. Установка этого контракта больше не обращается к репозиторию или хранилищу ассетов. Остальные зависимости npm и ОС устанавливаются штатно; полная автономность от Интернета этим не подразумевается.

Включены 14 неизменённых файлов `@neurocenter/asset-contract` 1.2.1 — 61 664 байта, без runtime-зависимостей. Происхождение и Git blob SHA закреплены в [SOURCE.json](../vendor/asset-contract/SOURCE.json), лицензия сохранена в [NOTICE.md](../vendor/asset-contract/NOTICE.md), опись — `SHA256SUMS`. Пакет не содержит каталога, recipes, скиллов, промптов, runtime-архивов и весов моделей.

Закрепление библиотеки и закрепление описей ассетов имеют разных владельцев. `SOURCE.json` задаёт версию кода проверки, а `services/shared/asset-source.lock.json` — проверяемый источник компонентов. Обновление источника не требует скачивать библиотеку заново и не переключает назначения проектов.

Зависимость Root использует `file:vendor/asset-contract`, сервисов — `file:../../vendor/asset-contract`. В Docker локальные файлы копируются в `/vendor/asset-contract` до `npm ci`; этот путь сохраняется после `npm prune`. Контракт Gateway остаётся сборочной зависимостью: готовая схема OpenAPI уже включена в его сборку.

Из корня проекта проверка выполняется закреплённым Node 24:

```sh
node --test scripts/test/asset-contract-vendor.test.mjs scripts/catalog-plugins/test/prepared-source-snapshot.test.mjs
```

Проверка создаёт отдельный каталог без `node_modules`, новый HOME и npm-кэш. Настоящий `npm ci --offline --ignore-scripts` устанавливает локальный Root-пакет; ESM/CJS загружают его из этого каталога. После `prune --omit=dev` runtime остаётся доступным. Сетевой перехват запрещает и учитывает попытки запросов; старый вариант зависимости отдельно проверяется при недоступном asset-host. Это не заменяет сборку контейнеров или серверную приёмку.

Для обновления контракта выберите полный upstream commit, сверьте все исходные байты и обновите `SOURCE.json`/`SHA256SUMS`. Сохраните только минимальный runtime/CLI и его документы. Пересоздайте локальные lock-файлы, проверьте Root/Catalog/Gateway и явную опись `prepared-source-snapshot.mjs`; прежние descriptors, карточки и назначения не заменяются копированием vendor.
