# Плейтест: настоящие сборки архивов и отказ в доступе

Проверены новые сценарии упаковки и восстановления интерфейса после ошибки. Найденные дефекты исправлены; локальный catalog-service обновлён, все шесть локальных сервисов отвечают readiness/HTTP 200. Машинный итог: [report.json](../output/playwright/neurocenter-playtest-next/report.json).

## Исправления по результатам воспроизведения

- Обычный TAR из macOS, созданный от `.`: служебный AppleDouble `._.` больше не блокирует чтение. Проверки ссылок, родительских путей и размеров сохранены. Исходный красный архив с тем же SHA-256 принят после исправления.
- Внешняя папка архива с именем `build`, `dist` или `node_modules` снимается перед фильтрацией вложенных файлов, как при выборе папки. Архив больше не превращается в ошибочно пустой проект.
- `.mts` и `.cts` согласованы между интерфейсом, API, npm/repository, schema и компилятором. Декларации `.d.ts`, `.d.mts`, `.d.cts` исключены из выбора и отклоняются до очереди: пустой плагин больше не получается из декларации.
- Выбор папки пропускает конфиги registry и метаданные macOS. NFD-имена файлов сохраняются без переименования, а эквивалентные Unicode-пути по-прежнему считаются дублями. Это сохраняет соответствие строки import настоящему имени файла.
- Автоматический entrypoint следует типу инструмента: MCP — `bin`, плагин — `module`/`main`. Ручной выбор сохраняется при смене типа, новый набор файлов сбрасывает его.
- «Операции» очищают список, журнал, счётчик и прогресс при 401/403. Старые ответы не возвращают данные. Открытое подтверждение отмены закрывается, Enter после отзыва доступа не отправляет действие. Подтверждение получило доступное имя. При 503 сохраняется возможность повторной проверки.
- Нестроковый JSON-путь отклоняется как BadRequest; его методы не вызываются при формировании ошибки.

Один запрос публикации перехвачен и проверен по телу: `kind: plugin`, `source.type: files`, entrypoint `src/plugin.ts`; настоящая карточка не создавалась. При отзыве отдельной dev-сессии запрос архива получил 401, форма исчезла, показан экран входа. GET logout без служебного заголовка получил ожидаемый 403; для отзыва использован корректный `X-Neurocenter-Request: 1`.

## Границы

Настоящие публикации, установки в профиль пользователя, привязки папок и изменения бизнес-данных не выполнялись. Runtime запускался только в отдельных тестовых каталогах; проверена одна нативная платформа. Реальные Blitz, остальные семь целей и промышленное развёртывание этим проходом не подтверждены. Снимок перед перезапуском не показывал активных заданий; полный набор metrics недоступен (403), это записано отдельно в [restart-readiness.json](../output/playwright/neurocenter-playtest-next/restart-readiness.json).

Неблокирующее замечание для следующей полировки: «Выбрать папку проекта» из карточки каталога ведёт в общий `/projects`, где проект приходится выбирать снова. Вход и возврат со страницы подключения сохраняют контекст каталога.

В каталоге проекта отсутствует `.git`, поэтому коммит, push и сверка удалённой ветки не выполнялись. Установленный мост и его дистрибутив не менялись. Первые параллельные проверки CLI попали в временно очищаемый Nest build каталог `dist`; после завершения сборки последовательный прогон прошёл 66/66. Это ошибка порядка тестовых команд, не результат изменения продукта.
