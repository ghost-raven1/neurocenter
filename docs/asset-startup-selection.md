# Ассеты на втором шаге dev.sh up

Обычный запуск в терминале — `scripts/dev.sh up`. На шаге **2 «Выбор и подготовка ассетов»** сначала устанавливается общий контракт, затем показывается проверенная поставка: имя, вид, версия, размер с зависимостями и отметка нового ассета или обновления.

Введите номера через запятую. `Enter` сохраняет прежний набор, `all` выбирает все доступные позиции, `none` сохраняет пустой набор, `s` пропускает загрузку только сейчас. На первой установке прежнего набора нет: пустой ответ не запускает скачивание. Ctrl+C отменяет запуск до остановки работающих приложений.

Выбор хранится локально в `.run/assets-selection.json`. После обновления закреплённой поставки сохраняются стабильные ID, а их версии берутся из новой проверенной описи. Новые ID автоматически в прежний набор не добавляются. Источник и его SHA проверяются повторно перед скачиванием. Выбранные зависимости добавляются по точным версиям; уже проверенные файлы SHA-кэша повторно не скачиваются. Это подготовка файлов: состав каталога и установки в проектах меняются отдельными действиями в интерфейсе.

Профили:

- `fast` (по умолчанию): в интерактивном терминале предлагает выбор без моделей; без TTY использует сохранённые файлы и не запускает предзагрузку.
- `standard`: подготовка выбранных инструментов и моста без весов моделей.
- `full`: позволяет выбирать модели и запускает настроенный хостинг моделей.

Для `standard`/`full` без TTY используется сохранённый набор ID или прежняя квитанция. Первый запуск без сохранённого выбора оставляет прежнее поведение CLI: выбирается вся поставка, разрешённая профилем. Чтобы явно ограничить автономную подготовку, сначала сохраните выбор в терминале или выполните `npm run assets:sync -- --asset ID`.

Локальный флаг `ASSET_STARTUP_SELECTION=off` в окружении либо `.env.local` отключает интерактивный вопрос. Для `standard`/`full` сохраняется прежний набор или исходный режим предзагрузки; отключение вопроса само по себе не отключает подготовку. Сервер флагов для установщика не требуется.

Если список или файлы поставки недоступны, приложения продолжают запуск с сохранёнными данными, а выбор остаётся для повтора. Отмена и повреждённая опись не объявляются успехом. Для автономного переноса используйте существующий `npm run assets:sync -- --offline-ready` с тем же набором `--asset ID`, перенесите весь `RUNTIME_ARTIFACT_DIR` и включите `ASSET_SOURCE_MODE=offline`.
