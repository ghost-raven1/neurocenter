# Кварки через RAG core: исправление от 25 октября 2026

Сбор сущностей из подтверждённого источника OpenCodeRAG для самообучения больше
не требует отдельного Web UI. Публикация, список установок и выполнение используют
общий контракт ядра и проверку выбранной установки в режиме `core`. Содержание
сохраняется как сообщённый опыт с неизвестной уверенностью и требует проверки.

## Поведение

- Установка с подтверждённым ядром и поддержкой кварков доступна для сбора.
- Прежние установки с поддерживаемым UI сохраняют совместимость.
- Некорректный явный контракт ядра не подменяется старым UI-контрактом.
- Узнанная старая установка без подтверждённого формата остаётся видимой:
  интерфейс предлагает обновление и блокирует отправку.
- При отзыве одобрения, смене привязки или отключении функции сбор прекращается
  перед следующей записью. Уже принятые записи остаются в истории.
- Повтор не дублирует принятые сущности. Новая ревизия одобрения требует нового
  авторизованного задания; старое задание не получает новые права автоматически.

## Оставшаяся работа

Этот срез не подтверждает работу через живую БД, браузер и установленный мост,
установку свежего архива или применение в main. Общий регресс моста сохраняет
открытый дефект публикации диагностической квитанции; его FALSE не отменён.

Полный перенос RAG UI также остаётся открытым: нужны встроенные просмотр,
раскрытие и поиск локальных фрагментов через ядро с привязкой к снимку. Кнопка
отдельного окна и Web UI в рецептах пока сохранены. После проверки встроенного
пути следует удалить отдельный фронтенд из поставки.
