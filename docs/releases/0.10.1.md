# Neurocenter 0.10.1

Patch-релиз приложения с мостом **0.9.17**.

## Изменения

- Прямое добавление скилла архивом из формы каталога. SKILL.md определяется во вложенной папке; при нескольких скиллах пользователь выбирает нужный. Ресурсы сохраняются вместе с инструкцией.
- Упаковщик выбирает экспорт OpenCode-плагина вместо его установочной CLI и сохраняет optionalDependencies с учётом платформы.
- Известные чтения соседних ресурсов, которые JS/TS-сборщик не переносит, отклоняются до публикации. Интерфейс показывает понятную причину и доступный вариант поставки.
- Новая самостоятельная поставка моста 0.9.17 включает проектных агентов и сбор опыта для проектного самообучения. Функции моста сохранены относительно 0.9.16; исправления упаковщика относятся к серверу и интерфейсу приложения.

## Обновление

Новых миграций базы данных нет: используется история 0–10 из 0.10.0. Перед обновлением сохраните резервную копию Catalog.

Новая версия моста публикуется отдельно в neurocenter-assets. Приложение закрепляет commit источника и контрольные суммы архивов. Подготовленная поставка доступна через API Gateway; проверка источника и публикация релиза сами не заменяют мост на компьютере. Чтобы обновить компьютер, запустите установщик из интерфейса «Мои компьютеры». Для доставки сборщика опыта повторно примените агентов проекта и перезапустите OpenCode.

Свободное место для npm-сборки инструментов должно покрывать резерв упаковщика. Релиз не отключает проверку места и не меняет пользовательские профили автоматически.

## Проверка

Проверки приложения и точных автономных архивов записываются в манифест релиза. macOS ARM64 проверяется нативно; Linux x64 — в Docker amd64 с эмуляцией на macOS ARM64. Внешнее production-развёртывание и остальные нативные платформы в этот выпуск не входят.
