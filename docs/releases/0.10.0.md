# Neurocenter 0.10.0

Объединённый релиз приложения. Версия моста: **0.9.16**.

## Изменения

- Проектное самообучение: опыт, гипотезы об агентах и проекте, проверки, ручное одобрение и отзыв знаний. Генерация гипотез запускается только кнопкой.
- Мост передаёт ограниченную статистику работы OpenCode без промптов, аргументов инструментов и результатов. Применение знаний требует решения человека.
- Настраиваемый источник релизов моста, проверка новых версий и отдельное подтверждение импорта. Установщики доступны через API Gateway.
- Упаковка скиллов из архивов и GitHub, включая прямую ссылку на SKILL.md; обработка ошибок и недостатка места.
- Контейнерные установки npm изолированы от .npmrc хоста и проекта; источник пакетов закреплён на официальном npm registry с проверкой TLS.
- Включены ранее объединённые изменения каталога, агентов, моделей, заявок, интерфейса компьютеров и Swagger.

## Обновление

Catalog применяет миграцию **10** после существующих миграций 0–9. Контрольные суммы старых миграций сохранены. Перед обновлением сохраните резервную копию Catalog PostgreSQL. Откат приложения после миграции требует согласованного восстановления базы из резервной копии.

Для сбора опыта обновите мост до 0.9.16, повторно примените агентов проекта и перезапустите OpenCode. Пользовательские промпты и глобальные разрешения автоматически не заменяются. Старые мосты можно обновить через интерфейс компьютеров.

Ассеты выбираются отдельно: выпуск приложения сам по себе не импортирует все карточки и не скачивает модели. Необходимые версии источника и артефактов зафиксированы в манифесте релиза и asset-source.lock.json.

## Область проверки

Релиз предназначен для публикации в GitHub и локального запуска. Проверки и контрольные суммы опубликованы отдельным манифестом. Внешнее production-развёртывание и приёмка на остальных нативных платформах в этот выпуск не входят.
