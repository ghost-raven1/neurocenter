# Мост, чаты и надёжность — 24 октября 2026

Код 789b9e8ae51fe6b2757d117781ae648318e5c50a объединён в main и origin/main и применён на рабочем Mac. Изменённые 19 production-файлов Catalog совпали побайтово с Git и запущенной immutable generation. База использует schema 32, Catalog прошёл passive readiness, у установленного моста свежий heartbeat. Все 75 файлов соседней незавершённой работы сохранили байты и mode.

## Поведение после исправлений

Ошибка моста ограничивает зависимое от него исполнение. Серверные ответы в смешанном личном раунде запускаются первыми; системные роли и командные комнаты имеют отдельные очереди исполнения server/device-codex. Готовый ответ сохраняется, пока другой адресат ждёт Codex. Порядок вопросов внутри комнаты остаётся FIFO, другие комнаты продвигаются независимо.

Сохранены общие пределы приёма: 8 системных заданий, 100 вопросов проекта и 20 вопросов автора. Один транспорт занимает максимум 7, 99 и 19 мест соответственно. Это оставляет место другому транспорту и не увеличивает нагрузку. Смешанный вопрос занимает оба канала только по незавершённым адресатам; учитываются закреплённые версии моделей. Повтор принятого запроса возвращает прежнюю квитанцию. История, готовые ответы, отмена, права и флаги сохраняют свои проверки.

Старые полностью занятые очереди сохраняются до завершения, отмены или истечения прежнего срока. Обновление не вытесняет задания. Codex через недоступный компьютер требует восстановления именно этого компьютера; автоматической замены модели или платного повтора нет. Общий предел исполнения двух транспортов проекта действует внутри одного экземпляра Catalog; между репликами SQL исключает двойной claim комнаты, но общий transport-лимит ещё не распределён.

Устранены две причины инцидента: сохранение мастера провайдера больше не наследует контекст завершённого задания, а heartbeat не зависит от успешной отправки старой квитанции. Poll Codex принимает уже подтверждённый результат при гонке завершения; допуск нового вызова продолжает проверять текущие права, модель и привязку. Завершённый платный ответ при такой гонке не превращается в ложную ошибку смены прав.

В ответах командных агентов атомарно сохраняется learning receipt: revision/digest и точные ссылки на одобренные знания. Публичная проекция не содержит исходного текста знаний. Сохранён резерв диска для builder, завершение которого ещё не подтверждено.

Подробности: [комнаты](project-chat-room-isolation-2026-10-24.md), [приём вопросов](project-chat-admission-isolation-2026-10-24.md), [приём системных ролей](system-role-admission-isolation-2026-10-24.md).

## Живой Codex, установка и интерфейс

Один новый запрос через прежнюю импортированную GPT-6.1-Sol прошёл API → установленный мост → настоящий Codex → сохранённый личный ответ в 06:03:45–06:03:59 UTC, до последней правки admission. Транспорт Codex с тех пор не менялся; этот запрос не является новой живой приёмкой всех путей финального среза. Случайный marker ответа совпал; учёт: 26 входных и 13 выходных токенов. Автоматического повтора не было. Ответ отдельно проверен в UI; проверочная вкладка закрыта, запись диалога сохранена. Старый ошибочный turn остался историей: безопасного API восстановления его содержимого из отдельной device-квитанции нет.

Установлен мост 0.9.18, build 36a217c9d19d4694203fa3a9e032f4b4785fa3a040ee6902214a6eb4f46cd9ab. Все 15 проверок сохранности подключения/ключей/ручных настроек прошли. Архив darwin-arm64 SHA256 626fb1b095864d1be3fae94eaafadccaa6d632461d252f9c70fa737e0cf918ff прошёл 6/6 сценариев установки, включая отсутствие системных Node/npm/curl, ручной JSONC, повтор, badSHA и настоящий native OpenCode tool/stream. Provider в архивной проверке — локальный HTTP fixture Ollama; реальные Ollama weights этим прогоном не проверены. Временный профиль удалён.

Системные роли открываются через «Каталог → Агенты → Системные агенты»: ИИ-администратор, Автоконфигуратор, Индексатор. Там выбираются модель, задача и согласованный контекст; редактора встроенных системных prompt/прав в этом окне нет. Упаковщик находится в сценарии упаковки.

При первоначальном допуске порог свободного места 8 ГиБ не был выполнен; после очистки место освободилось, новый допуск и запуск этого профиля не проводились. - Измерить CLI/native-adapter и остальные языки отдельно; закрывать конкретные ветви отказа, а не только увеличивать общий процент.
- Резерв роста диска для незавершённого builder хранится в процессе. Его сохранность после перезапуска и согласование между репликами требуют отдельного постоянного журнала; текущая проверка этого не подтверждает.
- Распределённый лимит исполнения между несколькими Catalog-репликами и численные квоты проекта остаются отдельной работой; [проект квот](project-quotas-design-2026-10-24.md) не объявляется реализацией.

- Приёмка Linux/Windows, внешний DR, CI и production не подтверждены этим локальным запуском. Skills/Gateway проверены по liveness/владению; их readiness с побочными записями намеренно не вызывались.
