# Embedding-модели и поиск по проекту

Модель добавляется главным администратором через **Ассеты** из `neurocenter-assets` либо настраивается как удалённое подключение во вкладке **Модели**. Импорт карточки и размещение весов — разные состояния. Сначала выберите модель, затем **Запустить** и **Проверить**: успешная содержательная проба фиксируется отдельно от доступности runtime.

В проекте выбираются проверенная версия модели и размерность. Для готового индекса смена модели или размерности проходит через управляемую переиндексацию. Старая активная генерация продолжает обслуживать поиск до успешного переключения. Совпадение размерности само по себе не делает две модели совместимыми. [Подключения, конфигурация OpenCode и ограничения](remote-models.md).

Локальная модель имеет immutable runtime alias по SHA манифеста. Размещение другой версии того же публичного имени не заменяет версию, используемую проектом. Файлы подготавливаются только из проверенной поставки импортированного ассета. Сетевого fallback к `/api/pull`, default-модели или standalone-реестру нет. Установка на компьютер и доступ проекта проходят через мост и API Gateway.

Профиль `scripts/dev.sh up --profile full` предзагружает текущие ассеты и запускает общий runtime. Он не импортирует карточки и не активирует выбранную модель автоматически. `fast` запускает приложения без подготовки ассетов. Runtime находится в отдельном Compose-проекте checkout; пользовательский `~/.ollama` не подключается. [Запуск и поставка](../README.md#ассеты-запуск-и-обновление).

## Операторская проверка файлов

Подготовка и проверка принимают только новый source envelope и явный каталог. Проверка не запускает inference. Подготовка использует SHA-кэш, ранее полученный через импорт или `assets:sync`, без прямого скачивания из Ollama.

```sh
npm run models:prepare -- --asset ./asset.json --directory ./data/embedding
npm run models:verify -- --asset ./asset.json --directory ./data/embedding
```

Для собственного кэша подготовки добавьте `--blob-directory <каталог .blob>`. Отсутствующая, повреждённая или подменённая часть отменяет подготовку до активации. Незавершённый native-журнал можно восстановить отдельной командой `models:prepare -- --directory <тот же каталог> --recover-only`; неизвестные пользовательские изменения не затираются.

[Формат источника, SHA-кэш и доставка](assets.md). [Историческая локальная приёмка 19 октября](local-models-acceptance-2026-10-19.md) не заменяет проверку новой версии и текущего сервера.
