# Установка Docker Compose

Установщик проекта подготавливает Compose перед `npm ci` во всех пакетах:

```sh
scripts/dev.sh install
```

Для отдельной подготовки моделей или production-стека без установки npm-зависимостей:

```sh
npm run compose:install
```

Нужны Node.js 24+ и установленный Docker CLI. Docker Engine/Desktop устанавливается заранее. Во время установки плагина daemon может быть выключен; перед запуском сервисов его нужно запустить. Справка: `npm run compose:install -- --help`.

## Как работает установка

- Рабочий `docker compose` версии 2 или новее сохраняется, если поддерживает `up --wait` и `--wait-timeout`. В том числе сохраняется Compose 5 из Docker Desktop.
- При отсутствии подходящего плагина скачивается официальный Compose **2.40.3**. Версия, размеры и SHA-256 четырёх файлов закреплены в [compose.lock.json](../scripts/workspace/compose.lock.json).
- Поддерживаются macOS и Linux, архитектуры arm64 и x64. Установка пользовательская, без `sudo`: `${DOCKER_CONFIG:-~/.docker}/cli-plugins/docker-compose`. Доступ к GitHub нужен только при скачивании.
- Размер, SHA-256 и версия проверяются до замены. После замены проверяется вызов через Docker CLI. При ошибке возвращается предыдущий файл или ссылка, включая ссылку на Docker Desktop. `config.json`, credentials и Docker context не меняются.
- Одновременная установка защищена блокировкой. Обычная ошибка очищает временные файлы и разрешает повтор команды. После аварийного завершения проверьте PID в `.neurocenter-compose.lock` и отсутствие работающей установки перед удалением этого файла из каталога плагинов.

`scripts/dev.sh up` сначала проверяет Docker CLI, Compose и доступность daemon. Ошибка останавливает запуск до сборки и остановки предыдущих процессов. Плагин устанавливается явной командой `install`.
