## Найденные и исправленные дефекты

1. Новые `/api/runtime-limits` endpoints отсутствовали в Gateway access policy:реальный UI получал403. В той же границе generic project write запрещал text upload разработчику и search читателю. Добавлены точные методы/пути без расширения неизвестных routes. Regression:2 RED→25 GREEN policy tests.
2. Nest сериализовал отсутствующую receipt как пустой HTTP body. Каталожный RPC ожидал JSONnull, поэтому первая загрузка обрывалась до записи. Два controller explicitly сериализуют JSONnull. Regression:2 RED→3 GREEN на настоящих Nest HTTP boundaries.
3. GGUF «Новый импорт» объединял initial state с прежним optional receipt/model/file. Реальный браузер воспроизвёл отсутствие file input после сброса. Полная замена состояния на reset/activate; regression2 RED→25 GREEN controller/API/реальный AntD tests и повтор через браузер.
4. Декоративные иконки text actions попадали в доступные имена кнопок. Иконки скрыты от accessibility tree; «Найти» определяется точным именем в браузере.
