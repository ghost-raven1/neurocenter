# JSON шага инструмента в командном чате — 26 октября 2026

Пользователь показал ответ «Ревьювера» на «Привет!» с ошибкой «Модель не вернула законченный JSON шага инструмента» и подтвердил ту же Qwen, что выбрана у координатора. Исходная точка — `4b09d4be645b627d8930995b42a3da9cbaf52503`.

## Что установлено

При включённых инструментах сообщение сначала проходит отдельный выбор действия, даже если это приветствие. В этом пути `AgentToolsService` уже проверяет `assistant`, строковый content и `done_reason=stop` перед `agentToolAction`. Старый текст объединял ошибку JSON.parse и превышение 8192 байт; он не доказывает обрыв по лимиту. Для `done_reason=length` предусмотрен другой отказ до разбора JSON. Исходный ответ Qwen на пользовательском Linux неизвестен.

Инструкция JSON-этапа стояла перед профилем и обычной системной инструкцией «ответь пользователю». Кроме того, полностью корректный JSON внутри одного Markdown-блока отклонялся до проверки действия. Оба случая воспроизведены локально; это не доказательство точного содержания пользовательского ответа.

## Исправление

- Инструкция текущего этапа вставляется после последнего системного сообщения только в запрос planner. Учитывается, что сведения проекта могут стоять перед профилем. Порядок и роли исходных сообщений сохраняются; в финальный обычный ответ JSON-инструкция не переносится.
- Допускается один целый документ JSON без обёртки либо внутри одного целого Markdown-блока с языком `json` или без языка. Пояснения снаружи, несколько блоков, недописанный JSON и другой язык не принимаются. JSON не дописывается и не извлекается из произвольного текста.
- Предел исходного ответа 8 КиБ UTF-8 проверяется до снятия обёртки. Ошибки размера и формата различаются и дают следующее действие без публикации сырого ответа.

Схема действий, подтверждённые разрешения, флаги и их начальные значения, пределы модели, число шагов, выбранная модель/провайдер, ledger и запрет автоматического повтора не менялись. Формат ответа не подменяется native function calling или неподтверждённым structured-output API.
