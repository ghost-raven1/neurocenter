## Границы доказательств

Снимки подтверждают видимое состояние и геометрию. Они не подтверждают серверные мутации, внешний IdP, inference, установку плагинов или полноту доступности. Клавиатура и ошибочные состояния проверяются отдельными сценариями по мере исправлений. Production-сборка объединённого кандидата находится в очереди основного агента.

## Первые подходящие модели в новых черновиках

| Селектор | Initial / late metadata | Refresh / ручной выбор / очистка | Нет подходящей модели |
| --- | --- | --- | --- |
| Анализ опыта проекта | Первый доступный chat/vision после чтения assigned-каталога | Изменённое значение и explicit clear сохраняются | Действие «Открыть модели проекта» |
| Испытание агента | Первый server-eligible available; загрузка/проверка квитанции не подменяется новым выбором | Fixed модель и модель последней квитанции сохраняются, ручной выбор не заменяется | Прежнее действие открытия моделей проекта |
| Провайдер OpenCode | Первый verified/current вариант текущего runtime после catalogReady | Черновики раздельны по типу провайдера; handoff, ручное значение и очистка сохраняются | Модели проекта или настройка моста по конкретной причине |
| Embedding проекта | Только новый выбор revision=0: assigned, verified, не archived, совпадающая ожидаемая размерность | Сохранённая модель, сохранённая очистка revision>0 и ручной clear не заменяются | Прежняя ссылка на каталог моделей |
| Использование моделей | Агрегат «Все модели» — аналитический фильтр, не черновик запуска | Не изменён | Все модели остаются в отчёте |
| Упаковщик | Передан основному агенту | Вне этого коммита | Вне этого коммита |
| Чаты / системные роли / semantic chat | Переданы владельцам этих модулей | Вне этого коммита | Вне этого коммита |

Общий predicate публичной готовности находится в ModelCatalog и используется анализом обучения и OpenCode-провайдерами. Сервер повторно проверяет актуальность и права при явном запуске. Добавление defaults не сохраняет выбор, не запускает inference, не открывает локальное окно и не перестраивает индекс.
