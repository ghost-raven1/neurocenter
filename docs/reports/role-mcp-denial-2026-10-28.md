# Причина отказа MCP в истории системной роли

В UI стенда F на Main `991b1101` обнаружены два безопасных MCP-инструмента, подтверждён только `qa_ui_echo`. Протокольный QA-провайдер однократно предложил точный ключ второго инструмента. Ключ получен штатным helper из фактического discovery; поле `toolKey` не приписывалось ответу discovery.

Защита остановила исполнение: run завершился `failed`, один вызов модели учтён с usage 10/12, вызовов и сессий MCP — 0. История и отказ сохранились после reload без повторной отправки. Независимая проверка БД и 33 UI-артефактов подтвердила результат. Однако UI и trace показывали общий конфликт контекста, поэтому F42-03 остаётся PARTIAL.

Правка добавляет в существующий безопасный классификатор точное сообщение штатного MCP-guard. Новый отказ объясняет неразрешённый инструмент либо некорректные аргументы, блокировку вызова и необходимость заново подготовить и подтвердить контекст. Причина сохраняется обычным механизмом истории; уже сохранённые записи не переписываются. Правила исполнения, права, счётчики и миграции не меняются.

Проверки: фактический `withRoleMcpTools` → фактический `SystemRoleService.fail` для невыбранного инструмента, ограничения делегата и аргументов-массива. Подтверждены отсутствие tool dispatch/trace, сохранение состояния и безопасная обработка обычной Error с похожим текстом. Причинный RED: 36 PASS / 3 FAIL именно по отсутствующему объяснению; GREEN: 39/39, Catalog TypeScript и diff-check прошли. Независимое source review — CLEAR.

Первый черновой тест ошибочно ожидал проверки значений JSON Schema на этой границе и исправлен на существующий контракт формы аргументов; исходный результат сохранён. Первый TSC остановился из-за отсутствующего cached root dependency link в новом checkout; после настройки ссылок на существующие зависимости проверка прошла без соседних правок исходников.

Production build на `64a2390c` прошёл за 8,45 с с ограничением heap 1536 МиБ; процесс и его группа завершились. Архив содержит 1260 скомпилированных файлов и manifest, каждый байт проверен. Временная ссылка на cached root dependencies удалена, tracked source чистый.

Артефакты находятся в ignored `.run/role-mcp-denial-20261028/`; исходный UI-повтор — в `ready-chat-rag-recovery/output/playwright/mcp-denial-f-20261028/`, независимая БД-проверка — в Original `.run/release-main-acceptance-20261028/fullstack-ui/phase-f-db-proofs/`. Перед удалением checkout их нужно сохранить отдельно. Повторный browser GREEN подтверждён ниже; CI и production не подтверждены. Фаза F и её исходный PARTIAL сохранены как история проверки.
