# Каталог из текущих исходников приложения

Текущая поставка содержит 34 позиции: 21 готовый inline-агент/скилл и 13 source plans для инструментов, metadata моделей и архива моста. `catalog-source/manifest.json` закреплён SHA-256 в `services/shared/bundled-catalog.lock.json`. Вложены 68 прежних metadata blobs и новая inline-опись, необходимые рецепты, исходники Python context, точные Fetch/Codex source closures и dependency locks. Общий объём объявленных файлов — около 2,2 МБ. Runtime-бинарников, архивов прошлых поколений и весов моделей в рабочей поставке нет.

Content pin имеет отдельный формат `schemaVersion:2 / app-bundled / sha256:<index SHA>`. Он не выдаётся за Git commit. Все 22 прежних Git pin остаются доверенными для восстановления точных старых описей и архивов. Исторические snapshots и активные native receipts сохраняются, включая ранее импортированные карточки. При переходе к новому источнику история не переписывается.

Обычные CLI sync/update и Catalog refresh читают текущую опись из Git. Чтение retired metadata не имеет сетевого fallback. Синхронизация и прежние сохранённые выборы не скачивают модельные веса. Snip требует выбранного локального архива; его подготовленный adapter допускает только уже проверенный private cache, без автоматического GitHub Releases. Отдельно заданные пользовательские публичные feeds сохраняются. Прежний default bridge feed показывает `sourceReady:false / archiveRequired:true`; установленная версия и её квитанции остаются доступны. Актуальный approved bridge descriptor и применение архива проверяются отдельно.

На странице «Ассеты» source revision отделена от envelope version, native catalog version и локальной установки. Подготовка использует существующие очередь, UUID journal, отмену, runtime sandbox и публикацию. Новое тело содержит только стабильный component ID и exact application revision; произвольные пути и команды не принимаются. Рецепт проверяется до enqueue и ещё раз перед producer. Обновление карточки требует свежего подтверждения native/source CAS и сохраняет её ID. Текущий готовый пакет отмечается только при успешном bundled-задании с точной revision, совпадающем native head и активной source receipt. Проект и компьютер обновляются существующими отдельными действиями.

Producer approval `catalog-source/producer.json` закрепляет 158 SHA публичных входов, кроме самого descriptor и замыкающего manifest lock. Он входит в manifest SHA. Неподтверждённое изменение adapter/helper больше не может оставить прежний пакет текущим. Child проверяет producer до и после сборки; server сверяет `recipe.producer` из SHA-снимка до публикации. В runtime config эта служебная metadata не попадает. Retained producer содержит 160 файлов. Docker public closure доставляется настоящими COPY; node_modules/dist остаются служебными links за пределами исходников.
