# Наблюдение пользовательского OpenCode через мост

Выделенный срез `feature/bridge-first-cli-observation` основан на Main `4cecd755` и синхронизирован с Main `281cd09a` объединением `f88f76cf`. Он реализует пункты OpenSpec2.1–2.3: фиксированное device-global задание `inspect-opencode-cli`, его native-исполнитель и компактную строку версии в `/start` до выбора проекта. Произвольные команды, пути и секреты из браузера не принимаются. Поставка в основной runtime пока не выполнена.

При неизвестном ACK сохраняются исходный ключ и тело; UI читает квитанцию и повторяет тот же запрос только явно. Отключение новых действий сохраняет чтение и отмену. Смена пользователя, роли или компьютера отсекает поздние ответы; повреждённый журнал не заменяется пустым. Между вкладками сериализуется только создание первоначального журнала, без сетевого запроса под блокировкой.

Native запускает ограниченный `opencode --version`, проверяет владельца дочерних процессов и сохраняет только допустимую версию/состояние. Raw stdout/stderr и локальные пути не включаются в completion. Исправлен воспроизведённый сбой: при гибели родителя сообщение в закрытый IPC прерывало запись квитанции очистки. Канонические lowercase UUID теперь проверяются до поиска компьютера либо начала выполнения; существующие идентификаторы и хеширование прочих заданий не меняются.

Связанные квитанции в `.run`: `cli-observation-backend-canonical-20261029/current-validation-receipt.json`, `sql-root-independent-review.json`; `cli-observation-native-20261029/canonical-release-validation-receipt.json`, `root-source-independent-review.json`; `computer-setup-frontend-20261029/frontend-validation-receipt.json`, `root-independent-review.json`. Общий список проверенных файлов: `cli-observation-extraction-20261029/qualified-source-union.json`. Первые неудачные попытки и ограничения зависимостей сохранены.

Проверки после объединения: `cli-observation-postmerge-20261029/openapi.log`, `independent-input-review.json`, `owner-fixed-import-receipt.json` и `openspec-split-requirement-receipt.json`. Первый запуск обвязки завершился до тестов из-за неверного имени импорта; исходный лог сохранён. В следующем запуске OpenAPI прошёл, а строгая проверка документации выявила длинное требование; оба результата сохранены раздельно. Группа57069 завершена, временный HOME и собственные ссылки зависимостей удалены. Повторный прогон OpenAPI после изменения только структуры спецификации не выполнялся.

Новые SQL-таблицы не добавляются; quota46, reset47 и несвязанный исходный WIP не включены. Установленный мост, текущие dist и пользовательские конфиги/auth не изменялись. Исходная версия пакета0.9.25 сохранена для этого непубликуемого среза; существующий архив не заменялся.

Не приняты: browser→настоящая очередь→установленный мост, реальный пользовательский CLI, установка из архива, Linux/Windows, CI и production. Защищённая проверка локального pinned1.14.48 пока остановилась до исполнения CLI и не является доказательством совместимости. Установка OpenCode через мост2.4, локальные провайдеры3.x, самообновление4.x и перестановка основного мастера5.1 остаются открытыми. Общий план UI-приёмки273 этим локальным набором не увеличивается.
