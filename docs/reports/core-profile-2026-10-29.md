# Базовый профиль запуска — 29 октября 2026

`dev.sh install/build/up/watch` по умолчанию выбирают fast: без asset selection/prefetch, подготовки Native и сборки образа проверщика снимков. Основные Node-сервисы и PostgreSQL остаются обязательными; это не полностью автономная установка npm/ОС.

Базовый режим сохраняет signing identity, опубликованные архивы и настройки моста. Без executor Catalog запрещает новые публикации даже при прежнем свежем heartbeat; история, отмена, lease renewal и завершение принятой проверки не блокируются новым gate. Прежний процесс проверщика остаётся известен общему механизму остановки.

Все профили исключают автоматическую загрузку весов моделей, включая сохранённый выбор. Full использует только заранее подготовленный hosting image с `--pull never --no-build`; отсутствие образа не считается готовым hosting. Ручной `ASSET_SYNC_MCP_BIN` либо его отсутствие сохраняются при fast up/watch, в том числе после публикации новой watch-generation. Расширенный профиль сохраняет прежнее управление checkout Native.

- После исправления: 13 целевых CLI случаев и один настоящий watch собственных toy-сервисов — PASS. Watch подтвердил повторную публикацию после правки, сохранение прежнего рабочего процесса при ошибке компиляции и остановку собственных процессов/HTTP.

## Границы

CLI fixtures контролируют запуск сервисов и побочные эффекты, настоящий watch использует собственные Git/npm/Node и toy-сервисы. Реальные Docker build/load, полный app startup, PostgreSQL lease recovery при остановке, установленный Primary, CI и сервер пользователя этим набором не приняты. Сборка исходников и обновление работающей площадки фиксируются отдельно.
