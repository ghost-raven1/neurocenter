## Что остаётся проверить

- После разблокировки собственного Mac: открыть локальную форму защищённого MCP заново, ввести синтетический ключ и отдельно проверить авторизованное discovery, затем безопасный tools/call. Public-сценарий не заменяет эту проверку.
- Скомпилированные профили агентов, разрешённые инструменты в фактическом сообщении, hooks и исполнение BMAD/OpenSpec с реальными файлами/проверками. Наличие установленного инструмента проекта не доказывает изолированный набор инструментов агента.
- Потеря ответа после принятого задания, повтор по тому же ключу, отмена удерживаемого задания/позднее завершение, смена прав/проекта/флага и обновление/удаление с сохранением ручных файлов.
- RAG: реальный embedding/index/sync/retrieval/restore в этой связанной цепочке; обучение и повреждённый собственный Quirk-fixture. Текущий текстовый провайдер не реализует embeddings или coding tools.
- Backup/restore и подписанные снимки: фактическая попытка копии вернула 503 из-за отсутствующего запускаемого `pg_dump`; ложная копия не появилась. Нужны доступный backup tool и собственная цель восстановления. У снимков отсутствуют хранилище/ключ подписи.
- Другие пользователи/отзыв доступа и внешний IdP. Исторические 503 входа остаются неразобранной проблемой доступности.

Bridge-first ComputerSetup, локальные провайдеры, квоты токенов и полный/частичный reset — отдельный WIP вне этой версии. CI, production, Windows и физический Linux этим проходом не приняты. Подтверждение очистки временного стенда/моста даёт отдельная квитанция его владельца; этот документ сам их не останавливал.
