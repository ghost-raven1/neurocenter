# Десктопная приёмка: проект → компьютер, 1 ноября 2026

Проверена ограниченная цепочка на собственном изолированном стенде с PostgreSQL 16, реальными API и мостом. Вход использовал dev-auth; это не проверка IdP, сервера пользователя, CI или production. Приёмка всех пользовательских сценариев не завершена.

Настоящий инертный skill прошёл публикацию, закрепление и одобрение точного состава проекта, затем установку двух файлов. Повреждённый архив не уничтожил прежний черновик. После ручного изменения установленного файла интерфейс обнаружил расхождение; отмена repair сохранила изменение. Подтверждённый repair восстановил исходные байты и сохранил ручной вариант в backup журнала. Затем через редактор опубликована версия2: проект и компьютер оставались на версии1. Явное закрепление версии2 не изменило установленную версию1; после отдельного одобрения и установки версия2 подтверждена файлами и manifest. Это проверка доставки файлов, не исполнения полезного кода skill или платной модели.

## Найденные ошибки и состояние исправлений

- Действие выбора папки открывало начало мастера. Исправление разделяет folder step3 и computer step0; общий helper проверен независимо. Сохранение контекста проверено компонентными тестами; повтор ссылки папки в настоящем браузере прошёл (`folder-link-fixed.yml`).
- Ссылка установки моста из Settings открывала OpenCode step1. Исправлена на computer step0; независимый review, компонентный regression и browser retest прошли (`settings-link-fixed.yml`).
- При включённой новой навигации терялся legacy archive deep link: прежний экран потреблял одноразовое намерение до ответа флагов. Исправление ожидает известный флаг только при `archive=open`; обычная история не блокируется. ON-путь в свежем браузере повторно открыл нужную модальную форму после redirect с сохранением query `qa` и hash. OFF-путь также открыл окно на /assets с сохранением остальных query/hash. ON/OFF дополнительно проверены реальным router/AssetSources в компонентных тестах; это не новая запись импорта.

Существующие ограничения функций отделены от этих ошибок: обновление skill через упаковщик, restore пустого RAG-снимка, методики на Windows, MCP обычных агентов, изображения/OCR и управляемое обновление моста не следует объявлять завершёнными по успешной установке инертного skill. Текущий код текстовых знаний уже существует как отдельный candidate; старый незакрытый checkbox сам по себе не доказывает отсутствия реализации.
