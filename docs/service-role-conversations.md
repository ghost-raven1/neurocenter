# Отдельные чаты системных ролей

В шапке откройте **Чат**, затем в поле **Чат роли** выберите Координатора, AI-админа, Автоконфигуратора, Индексатора или Упаковщика. У каждой роли свои диалоги, история и черновик. Для проектной задачи выберите нужный проект.

Новая задача проходит подготовку контекста и явное согласие на передачу выбранной модели. Роль нового диалога закрепляется на сервере; заменить её другой ролью в отправляемом запросе нельзя. При переходе к другой роли незавершённый текст сохраняется. Настройки контекста и согласие после повторного открытия проверяются заново.

В **Истории** соответствующей роли доступны и прежние смешанные диалоги. Они показывают только сообщения выбранной роли с исходными идентификаторами и действиями. Новую задачу отправляйте через **Новый диалог**. Чтение прежней истории не публикует её участникам проекта.

Если подтверждение отправки потеряно, используйте **Проверить отправку**. Эта проверка читает исходный запрос и не обращается к модели. **Повторить тот же запрос** использует прежний ключ и контекст. При выключенной функции или роли новые отправки запрещены, а разрешённые история, проверка принятия и отмена остаются доступны.

Администратор управляет новыми чатами флагом `service_role_conversations`; также действуют `system_role_chat`, флаг выбранной роли и права проекта. Для новой задачи нужна роль администратора проекта или главного администратора. Возможность чтения и отмены уже принятой собственной задачи проверяется отдельно.

Технически новые диалоги и прежняя история используют API `/api/system-role-chats`. При создании нового диалога `agentId` обязателен. Новые задачи в прежних смешанных диалогах не принимаются; исходный подтверждённый запрос можно перечитать и точно повторить. Параметр `agentId` при чтении выбирает срез истории, а исходные URL проверки запросов и отмены не меняются. Миграция 43 добавляет закреплённую роль без переноса сообщений и без изменения их ключей. Выключение функции не требует удаления схемы или данных.
