# API и Swagger

Swagger UI доступен по `/api/docs`, OpenAPI JSON — по `/api/docs/openapi.json` на том же адресе, что и Нейроцентр. Для локального запуска: [Swagger](http://localhost:5173/api/docs).

Версия Swagger UI закреплена на `5.14.0` через `overrides` Gateway и его lock-файл. NestJS-адаптер `@nestjs/swagger` использует отдельную нумерацию версий.

Сначала войдите через обычный интерфейс Нейроцентра. Документация использует текущую браузерную сессию; каждый запрос к ней заново проверяет доступ. Токен устройства не даёт доступа к документации. Если проверка входа временно недоступна, сервер возвращает 503.

«Try it out» выполняет настоящие запросы с правами текущего пользователя. Сессионная cookie передаётся автоматически, защитный заголовок добавляется интерфейсом Swagger. Серверы и ресурсы Swagger используют текущий origin; внешние валидаторы отключены. Введённые через Authorize токены не сохраняются между открытиями страницы. Bearer-токен применим только к операциям, которые действительно поддерживают устройства.

Схема объединяет публичные HTTP-маршруты Gateway и проксируемых сервисов. Внутренние маршруты между сервисами и Socket.IO в неё не входят. Параметры, тела и ответы извлекаются из TypeScript; ограничения серверной проверки могут быть строже статического типа. Участки без явного типа помечены `x-neurocenter-untyped`. Потоковые ответы, архивы, перенаправления и специальные заголовки описываются отдельно.

Сборка Gateway и `start`/`start:dev` обновляют схему автоматически. Для отдельной генерации из корня репозитория:

```sh
npm --prefix services/api-gateway run docs:generate
```

Нужны Node.js 24 и зависимости Gateway. Генератор читает исходники, не запускает сервисы, миграции или подключения к базам. JSON копируется в `dist/docs/openapi.json`; production использует готовый файл. После изменения контрактов других сервисов пересоберите Gateway.

Проверки:

```sh
node --test scripts/test/openapi-document.test.mjs
npm --prefix services/api-gateway run build
node --test scripts/test/api-documentation-http.test.cjs
```
