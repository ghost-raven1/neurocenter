**Как читать матрицу.** `Source` указывает существующий entrypoint/владельца поведения; это не доказательство результата. Каждая ссылка Source/T содержит точный repo-relative путь; подпись сокращена до владельца и имени файла. `T` означает «ближайший тест существует», **не запуск и не полный охват строки**. Столбец «Выполнено» ссылается на отдельную квитанцию ниже; «не выполнен» означает отсутствие свежего узкого доказательства в этом отчёте, даже если такой тест когда-то входил в общий suite. `B26` — 26 браузерных наблюдений, из них 23 экрана и 3 проверки навигации/истории/списка. Строки матрицы — семейства, а не все комбинации условий. Если «Выполнено» содержит только FRESH-T, подтверждён запуск ближайших тестов; другого свежего исполнения пользовательского потока в этом отчёте нет.

R1 — наблюдатель проекта, R2 — разработчик, R3 — администратор проекта, R4 — главный администратор. Это сокращения минимальных рабочих уровней, а окончательное решение принадлежит текущим server capabilities/owner/project/model ACL. Системные agent roles не являются пользовательскими access roles. Указанные флаги ограничивают новые действия; историю, отмену и восстановление следует проверять независимо от их выключения.
