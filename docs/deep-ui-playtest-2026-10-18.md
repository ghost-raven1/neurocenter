# Владельцы форм и восстановление интерфейса — 18 октября 2026

Продолжен плейтест локального приложения. Проверены первый запуск, смена владельца открытой формы, поздние ответы, выдача доступа по нескольким проектам, отказы моста, metadata упаковки и восстановление прогресса. **833 frontend-теста прошли без падений и пропусков; TypeScript и production-сборка успешны.**

## Исправления

| Проблема | Новое поведение |
| --- | --- |
| Start оставлял выбранный проект прежнего владельца | Список и выбор проверяются в текущем auth scope; новый владелец не видит прежний snapshot. |
| Переход этапа терял проект и якорь | Этап и проект определяются URL; query/hash сохраняются, ссылки расширений получают подтверждённый проект. |
| Start ограничивался первыми 100 проектами | Используется общий постраничный загрузчик. 101-й проект доступен мышью и клавиатурой и сохраняется после reload. Фоновое чтение не закрывает селектор. |
| Форма создания сохраняла черновик другого аккаунта | Смена аккаунта или прав закрывает и очищает форму. Обычное закрытие тем же владельцем сохраняет черновик. |
| Выдача доступа оставалась активна после смены роли | Форма сбрасывается; многошаговое сохранение прекращает последующие записи. Уже отправленный запрос не объявляется отменённым. |
| Поздний ответ старой формы менял новый экран | Создание, редактор и выдача доступа проверяют текущий store и срок жизни формы до callback, toast и следующих запросов. Позднее чтение файла и Clipboard также не меняют новый контекст. |
| Старый CRUD 401 завершал уже новую сессию | HTTP interceptor связывает запрос с владельцем. Поздний 401 старого владельца игнорируется глобальным signOut; актуальный 401 по-прежнему завершает сессию. Проверен и повторный вход того же пользователя. |
| После 403 мост показывал старое имя компьютера и локальный путь | Отклонённый ресурс очищается при 401/403/404. Временный 503 сохраняет известные сведения с предупреждением. Старый reload не отменяет чтение нового владельца. |
| Ошибка предпроверки npm/GitHub появлялась дважды | Остаётся одно сообщение у источника; при редактировании неверного значения оно исчезает. |

Общий контроллер доступных проектов перенесён из Store в Projects и используется двумя экранами. Небольшой общий owner guard заменяет разрозненные проверки трёх форм. Identity HTTP-запроса хранится в WeakMap, не попадает в заголовки или сериализуемый config. React, Ant Design и Redux сохранены, новые библиотеки не добавлялись. Backend и runtime моста не менялись и не перезапускались.

## Проверки через интерфейс

- **Start:** реальное начальное чтение, управляемая смена владельца, сохранение проекта/query/hash, 101 проект, выбор последнего мышью и клавиатурой, reload, 320 px.
- **Формы:** девять сценариев владельцев, позднего успеха/503, медленного чтения файла, новой карточки редактора, Browser Back и мобильной смены роли. В двухпроектной выдаче после смены владельца перехвачен только первый POST; второй не отправлен.
- **HTTP 401:** в отдельной UI-fixture после позднего ответа прежней публикации новый владелец остаётся авторизован; свежий 401 завершает его сессию. Оба POST полностью перехвачены: [receipt](../output/playwright/neurocenter-deep-playtest-20261018/bridge/unauthorized-ui.txt). Повторный вход того же пользователя дополнительно проверен regression-тестом.
- **Мост:** до отказа локальный путь и селектор присутствовали; после 403 оба убраны; 503 сохраняет известные сведения, 200 восстанавливает чтение. Настоящие финальные GET devices/jobs/installations вернули 200.
- **Упаковка:** настоящие metadata OpenCodeRAG 2.4.4 и opencode-snip 2.0.0, сохранение черновика при закрытии, запоздалые metadata после смены источника, сохранение явно выбранного типа. Повреждённый UTF-8 и отсутствие entrypoint блокируются; девятибайтовый corrupt.zip отклонён настоящим сервером с 400.
- **Восстановление упаковки:** искусственный RUNNING job с прогрессом 42% восстанавливается после двух reload; 503 сохраняет прогресс, 403 очищает недоступное задание. Повторного POST сборки нет. На 390 px документ не растягивается, нижние действия доступны прокруткой.

## Источники доказательств и ограничения

Настоящий сервер использован для обычных чтений, npm metadata и отказа повреждённого ZIP. Смена аккаунтов/ролей, искусственные проекты, отказы 401/403/503, задержанные публикации/назначения и RUNNING job — явно обозначенные browser fixtures. Успешные POST/PATCH карточек и прав в этих сценариях полностью перехвачены; серверные пользователи, права и инструменты не менялись. Это проверка UI lifecycle, не приёмка настоящего IdP.

Полный Vitest: **833 passed, 0 failed, 0 skipped**. Целевые наборы входят в это число и повторно не суммируются. Regression-тесты HTTP interceptor сначала воспроизвели два отказа, затем прошли. Финальная сборка включает последние исправления owner guards и фонового селектора. [Vitest JSON](../output/playwright/neurocenter-deep-playtest-20261018/frontend-tests.json). Независимый review проверил Start/shared projects, bridge и формы; найденные пробелы входа в старый reload и глобального 401 исправлены.

Все шесть локальных health/readiness вернули 200: [receipt](../output/playwright/neurocenter-deep-playtest-20261018/health.json). Backend-тесты повторно не запускались, его исходники не менялись. В Vite остаётся предупреждение о крупном основном бандле; существующее предупреждение Ant Design о defaultProps не скрывалось.

QA карточки, проекты, назначения и сборки не создавались. Собственные браузерные сессии завершены с logout 200 и последующим `/auth/me` 401. Сохранность исходных данных и конфигурации OpenCode сверена. Привязка локальной папки остаётся обязательной предпосылкой установки; отдельной нативной проверки в этот проход не было.

Настоящие Blitz/PKCE, внешний S3 и восстановление на другом хосте, семь остальных нативных целей и production-обновление по-прежнему требуют отдельных свидетельств. `.git` в рабочем каталоге отсутствует; push, CI и deploy не выполнялись.
