# Продолжение UI-плейтеста — 18 октября 2026

Проверены начало работы, каталог и редактор скиллов, проекты, базы знаний, участники и доступ, история, обслуживание и операции. Браузерные проходы выполнены на локальном стенде; основные экраны проверены на 1440, 390 и 320 px. Три агента проверяли независимые сценарии, основной агент проверял навигацию и общее восстановление после ошибок.

## Исправления

| Сценарий | Исправление и подтверждение |
| --- | --- |
| Выдача, смена и отзыв роли проекта отсутствовали в аудите | Назначение и событие фиксируются одной транзакцией PostgreSQL. Исполнитель проходит из доверенного контекста запроса. Повтор без изменений не создаёт ложного события; конфликт не возвращает ложный успех. |
| Открытая история не обновлялась после изменений доступа | Gateway уведомляет раздел `audit`. Три настоящих изменения назначения появились во втором окне без ручного обновления; изменение QA пользователя также пришло автоматически. |
| Подписи редактора каталога ссылались на скрытую форму создания | У форм уникальные имена Ant Design. Повтор create → close → edit подтвердил уникальные ID и правильный фокус по нажатию подписи. |
| Конфликт редактора показывал две одинаковые кнопки загрузки актуальной версии | При HTTP 409 оставлено одно действие; восстановление черновика сохранено. |
| Валидация почты дублировала ошибки | Оставлена одна ошибка Ant Design для пустой и неверной почты. |
| Поиск проектов растягивал экран 320 px до 369 px | Поле стало адаптивным; повтор подтвердил ширину документа 320 px. |
| Кнопка привязки папки растягивала экран 320 px до 329 px | Текст переносится, иконка остаётся рядом. Все три шага проверены на трёх ширинах без переполнения. |
| Ошибка времени обслуживания оставалась выше экрана | Сохранение прокручивает форму к первому ошибочному полю. |
| Ошибка сохранения обслуживания терялась над длинной формой | Сообщение перенесено к кнопкам сохранения; конфликт проверен отдельным UI-fixture. |
| Текст сброса настроек выходил за кнопку на 320 px | Кнопка переносит текст и увеличивается по высоте. |
| Сетевой отказ общего списка баз знаний выглядел как отсутствие баз | Явная ошибка и повтор загрузки. При временном отказе обновления предыдущие данные остаются с предупреждением; отказ в доступе очищает их. Старый ответ не подменяет новый. |

Аудит проектных назначений вынесен из крупного `CatalogDb` в небольшой `ProjectMemberRepository`. Остальная архитектура React, Redux и Ant Design сохранена; соседние модули массово не переписывались.

## Проверенные пользовательские сценарии

- Проект: валидация создания, создание QA проекта, вкладки и прямые ссылки, квота 1024 → 2048 МиБ с перезагрузкой, запрет нуля, создание и браузерное скачивание отдельной копии PostgreSQL размером 18 452 байта с совпавшей SHA.
- Скилл: создание через каталог с UTF-8 ресурсом, редактирование инструкции и пути ресурса, история версий, добавление в QA проект. Два редактора: реальный HTTP 409, сохранение черновика, загрузка актуальной версии и объединение до версии 4.
- Доступ: создание и нормализация почты, запрет дубля, конфликт двух форм, выдача/смена/отзыв проектной роли, защита последнего главного администратора без сохранения его настроек, поиск и выход.
- Операции: настоящая история, вторая страница, фильтр ошибок и подробности с журналом. Повтор и отмена исторических операций не запускались.
- Начало работы: три шага на трёх ширинах, справка LSP, возврат из справки RAG к нужному проекту. Каталог: поиск, пустая выдача и сброс, фильтр MCP, содержимое, сведения и история MCP Fetch.
- Базы знаний: общий список, читаемые имена проектов, переход к знаниям; блокировки синхронизации при отсутствии привязки папки объяснены явно.

Настоящие успешные записи сервера не подменялись. Искусственно прерывались только GET пользователей, истории, копий и RAG; после повтора получен настоящий ответ. Конфликт политики обслуживания и отдельная визуальная проверка единственной кнопки редактора использовали явно обозначенные fixtures. Реальные конфликты пользователя и скилла проверены отдельно.

Собственные QA пользователь, проект, скилл, назначения, копия и пустая RAG БД удалены с проверкой точного владельца. Остальные пользователи и исходный проект сохранены. Исторические события QA в аудите сохранены. Все собственные браузерные сессии завершены: logout 200, последующий `/auth/me` 401.

Глобальный профиль OpenCode, привязка рабочей папки и рабочие установки не менялись. Копия QA проекта была локальной; внешняя S3-доставка и восстановление в этом проходе не проверялись. Dev-вход не подтверждает настоящий IdP и отзыв активной сессии другого пользователя. Нативные платформы и модельная индексация не входили в этот UI-проход.

Перед локальными рестартами дважды проверялись очереди, операции, активность PostgreSQL и процессы копирования; активной работы не обнаружено. Метрики отвечали 403, поэтому наблюдение за in-flight запросами неполное и полная готовность мониторинга не заявляется. `.git` отсутствует: CI, remote и production-публикация не выполнялись.
