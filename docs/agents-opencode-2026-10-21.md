# Агенты OpenCode: каталог и проект

Агент — самостоятельный тип ассета `kind: agent`. Источник `neurocenter-assets` хранит descriptor, промпт, лицензию и точный исходный commit. Импорт создаёт связанную нативную карточку, а не плагин с дополнительным флагом. Базовый набор: Планировщик, Разработчик, Ревьюер, Тестировщик и Документатор.

## Пользовательский путь

Главный администратор управляет общими шаблонами во вкладке «Агенты» каталога: создаёт карточку, правит промпт и параметры, удаляет и восстанавливает её. Ассеты импортируются выборочно через существующий раздел «Ассеты».

Архивные карточки скрыты по умолчанию. Главный администратор открывает их переключателем «Показывать архив». Активное закреплённое назначение проекта остаётся видимым и управляемым даже после архивирования общего шаблона; удалённое назначение активным не считается.

Администратор проекта добавляет точную версию шаблона в проект. Первое назначение отключено. В проекте можно изменить промпт, описание, режим OpenCode, модель, разрешения и параметры генерации; сброс настроек возвращает закреплённый шаблон. Обновление общей карточки не заменяет настройки уже подключённых проектов. Переход на новую версию выполняется явно и сохраняет переопределения.

Изменение сохраняет желаемое состояние и одной пользовательской операцией отправляет полный набор выбранной папке через API Gateway и мост. При недоступном компьютере задание остаётся в очереди. Подтверждение относится к конкретным устройству, binding, instance и ревизии. Успех старого задания не подтверждает более новую настройку. Другие связанные папки требуют собственного применения.

Gateway пробуждает именно выбранный компьютер событием Socket.io после создания задания. Событие содержит только идентификаторы, без промптов и разрешений; периодический опрос остаётся механизмом восстановления связи.

Мост меняет только управляемые `.opencode/agents/nc-*.md`. Подтверждение означает, что файлы настроены. OpenCode перечитывает их при следующем запуске; работа конкретного провайдера или модели этим подтверждением не проверяется. Встроенные `build` и `plan`, глобальная конфигурация и чужие агенты сохраняются.

## Удаление

При удалении из общего каталога главный администратор выбирает последствия после просмотра связанных проектов. Вариант «только из каталога» сохраняет закреплённые версии в проектах. Вариант «из каталога и проектов» отключает назначения и увеличивает ревизии проектов. Физическое удаление из каждой папки подтверждает мост; архивирование карточки само по себе таким подтверждением не является.

Удаление из проекта отключает назначение и исключает его из следующего полного набора. История и проектные переопределения сохраняются. Повторное добавление возвращает сохранённые настройки в отключённом состоянии. Неизменяемые версии шаблонов не удаляются вместе с карточкой.

## Конфликты и восстановление

| Случай | Поведение |
| --- | --- |
| Две вкладки меняют одну карточку или проект | CAS по ожидаемой версии/ревизии отклоняет устаревшую запись; редактор сохраняет введённый текст |
| Потерян ответ сохранения или импорта | Тот же UUID возвращает сохранённый результат без второй версии |
| Повтор применения после известного отказа | Новый запрос создаёт новое задание; неизвестный ответ повторяется с прежним ключом |
| Компьютер offline | Состояние проекта сохранено; UI показывает очередь, а не подтверждённую установку |
| Права отозваны, папка изменилась или lease потерян | Сервер повторно проверяет доступ и точную цель перед исполнением/записью |
| Локальный файл изменён вручную, чужой агент перекрывает имя или путь содержит symlink | Безопасный отказ без замены чужих файлов |
| Процесс аварийно завершён во время записи | Незавершённая транзакция восстанавливает прежние файлы; завершённая повторяет сохранённую квитанцию |
| Потерян финальный ACK моста | Мост повторяет ту же квитанцию; подтверждённая операция не выполняется повторно |
| Удалена вся `.opencode` | Повторное подключение той же папки использует закрытое доказательство владения; удалять мост не требуется |
| Подложена копия project receipt | Без закрытого локального журнала она не даёт права удалять или заменять файлы |
| Входной объект, YAML, Unicode или размер некорректны | Проверка до записи; до32 агентов, промпт до64КиБ, полный набор до2МиБ |

## Данные и проверка

Миграция7 создаёт пять таблиц: `agent_catalog`, `agent_catalog_versions`, `project_agent_sets`, `project_agents`, `agent_mutation_requests`. Неизменяемые версии защищены SQL trigger, назначение ссылается на exact version+manifest. Старые миграции0–6 и их контрольные суммы не переписываются. Runtime readiness проверяет прежний физический контракт и новый контракт агентов вместе.

Журнал показывает имена, версии, ревизии, включение и признак изменения промпта по SHA. Полный промпт, разрешения и приватные данные не копируются в общую историю действий. Полный дамп каталога включает таблицы агентов; RAG snapshot остаётся образом LanceDB.

Контракт первого выпуска проверяется с закреплённым OpenCode1.14.48, включая фактически поддерживаемый `permission.bash`. Актуальная онлайн-документация OpenCode может описывать другой выпуск. Исходник закреплённого движка: [agent.ts](https://github.com/anomalyco/opencode/blob/v1.14.48/packages/opencode/src/config/agent.ts).

Для общего workspace/check сначала требуется корневой `npm ci --ignore-scripts`: cross-format тест моста использует закреплённый пакет `@neurocenter/asset-contract`. Нативная проверка OpenCode выполняется отдельно с SHA-проверенным бинарником в собственном временном HOME и проекте.

## Локальная приёмка 21 октября 2026

Через рабочий интерфейс импортированы пять агентов и bridge0.9.15: шесть результатов «Добавлено и проверено». В отдельном проекте настоящий Gateway и скомпилированный worker подтвердили создание и CAS-конфликт шаблона, очередь offline, повтор запроса без дубля, проектный промпт, сброс, включение/отключение, явное обновление закреплённой версии, удаление/повторное добавление и архивирование без потери проектных настроек. Закреплённый OpenCode1.14.48 независимо прочитал файлы и перечислил агентов; ручной `manual.md` остался неизменным.

CUA в браузере отдельно прошёл: пустую форму с ошибками обязательных полей, создание своей карточки, правку промпта с появлением v2, просмотр сохранённого текста, архивирование, фильтр архива и восстановление той же v2. В проекте кнопками проверены назначение, свой промпт, включение, отключение и удаление с точными подтверждениями моста. Одноразовые проект, устройство и профиль очищены; карточки QA архивированы с сохранением истории.

Финальный повтор с обязательным наблюдением настоящих Socket.io событий завершил10 этапов и10 применений: каждое задание стартовало через44–111мс после постановки в очередь. Финально собраны Docker-образы catalog, Gateway и frontend; запуск контейнерного стека этой сборкой не выполнялся.

Перед применением миграций локальный стек остановлен, PostgreSQL сохранён, созданы и проверены custom backups catalog/RAG. После применения сравнение с восстановленными копиями подтвердило сохранность1194 старых строк catalog и38 строк RAG; прежние контрольные суммы журналов не изменились. Исходные24 базы, их OID и старые registry/retirement записи сохранены при сквозной приёмке. Если собственная QA RAG-база успевала создаться автоматически, удалялась только она через штатные preview/digest/purge.

Пользовательский мост обновлён штатным установщиком через Gateway с0.9.14 до0.9.15 на прежнем device ID, без pairing. Credentials, workspace, registry и два глобальных файла OpenCode совпали побайтно; прежний runtime сохранён целиком. Пользовательским проектам агенты автоматически не назначались.
