# OpenCodeRAG: плагин и MCP для поиска по проекту

[OpenCodeRAG от MrDoe](https://github.com/MrDoe/OpenCodeRAG) доступен в каталоге двумя отдельными инструментами. **«OpenCodeRAG (плагин)»** подключает инструменты и обработчики самого плагина OpenCode. **«OpenCodeRAG» с типом MCP** — ранее опубликованный адаптер с ограниченным набором MCP-инструментов. Оба комплекта закреплены на `opencode-rag-plugin` 2.4.4; их установка и настройки различаются.

## Установка плагина через мост

1. Подключите компьютер через мост и свяжите локальную папку с серверным проектом.
2. В каталоге выберите этот проект и найдите **«OpenCodeRAG (плагин)»**.
3. Нажмите **«Установить через мост»**. Инструмент добавится в каталог выбранного проекта автоматически. При первом использовании администратор проверяет точный комплект кнопкой «Одобрить и установить»; ранее одобренная версия отправляется сразу.
4. Дождитесь завершения установки и перезапустите OpenCode в связанной папке. Зависимости входят в закреплённый комплект: устанавливать npm-пакеты на компьютере не требуется.

Плагин использует собственные инструменты и обработчики OpenCode. Если `opencode-rag.json` отсутствует, включена автоматическая индексация и используется локальная модель **`qwen3-embedding:4b`**, протокол **Ollama**, URL **`http://127.0.0.1:11435/api`**. Эти значения применяются в памяти; установщик не создаёт и не перезаписывает `opencode-rag.json`. Существующие настройки провайдеров и индексации сохраняются. Самообновление плагина отключено: обновления устанавливаются через каталог с проверкой комплекта.

В поставку входят основные инструменты и обработчики upstream-плагина. TUI и интеграция OpenCode V2 не включены. Распознавание изображений, дополнительное описание кода, decision-модель и reranking по умолчанию выключены; собственная конфигурация проекта может задавать их отдельно.

**Веса модели скачиваются отдельно.** Для хостинга модели в самом Нейроцентре выполните `npm run embedding:up` из корня его репозитория. Модель сохраняется в `data/embedding/`; проверка — `npm run embedding:check`, остановка с сохранением весов — `npm run embedding:down`. На macOS этот Docker-runtime работает на CPU. Если мост работает на другом компьютере, укажите в конфигурации плагина сервис, доступный именно с него: `localhost` всегда обозначает компьютер моста.

Пустой индекс и недоступная модель — разные состояния. Дождитесь завершения индексации и проверьте поиск в OpenCode. Ограниченная диагностика установки подтверждает загрузку плагина, но не заменяет проверку поиска с работающей моделью.

## Установка отдельного MCP-адаптера

Для адаптера выберите карточку **«OpenCodeRAG» с типом MCP** и установите её через мост. Затем в списке установок нажмите **«Настроить MCP»**, укажите URL сервиса эмбеддингов, модель, протокол и при необходимости API-ключ. Проверьте готовность настройки и перезапустите OpenCode из связанной папки.

Параметры локального мастера MCP сохраняются отдельно от проектных файлов; сервер получает состояние и ревизию настройки. Не добавляйте API-ключи в репозиторий. Чат-модель OpenCode не настраивает эмбеддинги автоматически. Тексты для эмбеддингов передаются выбранному провайдеру: используйте сервис, которому разрешено передавать содержимое проекта.

| Поле MCP | Что указать |
| --- | --- |
| URL | Доступный MCP-процессу OpenAI-совместимый `/v1` либо Ollama `/api` |
| Модель | Точный идентификатор embedding-модели выбранного сервиса |
| Протокол | `openai` или `ollama` |
| API-ключ | Ключ сервиса, если он требуется |

Для локальной модели Нейроцентра: протокол `ollama`, URL `http://127.0.0.1:11435/api`, модель `qwen3-embedding:4b`; ключ не требуется.

| Инструмент MCP | Назначение |
| --- | --- |
| `index_project` | Явно создать или обновить индекс связанной папки |
| `get_index_status` | Проверить состояние локального индекса |
| `search_semantic` | Найти фрагменты по смыслу запроса |
| `get_file_skeleton` | Получить структуру исходного файла внутри проекта |
| `find_usages` | Найти использования символа в локальном индексе |

В MCP-адаптере индексация запускается явно: вызовите `index_project`, дождитесь завершения, проверьте `get_index_status` и выполните пробный `search_semantic`. Автоматические обработчики плагина, TUI, описания изображений, decision-модель и reranking в адаптер не входят.

## Общая база знаний и восстановление

Для совместного использования откройте вкладку «База знаний» проекта и отправьте индекс кнопкой «Синхронизировать с сервером». Скачивание серверной копии заменяет локальный индекс, поэтому сначала сохраните нужный локальный вариант.

Размерность модели должна совпадать с существующим индексом. При несовпадении верните исходную модель либо подготовьте отдельный индекс в отдельной копии проекта. Одинаковая размерность сама по себе не делает разные модели совместимыми. При отказе провайдера проверьте URL, протокол, имя модели и ключ; не удаляйте индекс для исправления сетевой ошибки.

Комплекты доступны для семи целей. Intel Mac не поддерживается из-за native-зависимости LanceDB выбранной версии; другая архитектура не является заменой. Состав адаптеров и закреплённые версии описаны в `scripts/catalog-plugins/recipes/README.md` исходного репозитория Нейроцентра.
