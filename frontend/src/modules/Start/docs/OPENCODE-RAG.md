# OpenCodeRAG: поиск по знаниям проекта

[OpenCodeRAG](https://github.com/MrDoe/OpenCodeRAG) предоставляет семантический поиск по локальному индексу. Нейроцентр поставляет адаптированный MCP-комплект на основе `opencode-rag-plugin` 2.4.4. Возможности этого комплекта перечислены ниже; они не равны всем возможностям upstream-плагина.

## Подключение через каталог

1. Подключите компьютер к Нейроцентру через мост.
2. Свяжите локальную папку, например `~/projects/example-project`, с нужным серверным проектом.
3. В каталоге найдите OpenCodeRAG, выберите проект и установите доступный для вашей платформы комплект.
4. В списке установок откройте «Настроить MCP». Укажите URL сервиса эмбеддингов, модель, протокол и, при необходимости, API-ключ.
5. Проверьте готовность настройки и перезапустите OpenCode из связанной папки. Отдельная диагностика запуска доступна в интерфейсе после подтверждения.

**Модель эмбеддингов и её веса пока не входят в проект.** Нужен отдельно запущенный совместимый сервис. Он может работать на вашем компьютере или на выбранном сервере. Установка MCP сама по себе не устанавливает модель и не создаёт индекс.

## Параметры эмбеддингов

| Поле | Что указать |
| --- | --- |
| URL | Адрес доступного MCP-процессу сервиса: OpenAI-совместимый `/v1` либо Ollama `/api` |
| Модель | Точный идентификатор embedding-модели, доступной на выбранном сервисе |
| Протокол | `openai` или `ollama`; для OpenAI-совместимого сервиса явно выберите `openai` |
| API-ключ | Ключ выбранного сервиса, если он требуется |

`localhost` означает компьютер, на котором работает MCP. Адрес из браузера не обязательно доступен этому компьютеру. Чат-эндпоинт подходит только в том случае, если он также предоставляет API эмбеддингов.

Параметры локального мастера хранятся отдельно от проектных файлов; сервер получает состояние и ревизию настройки. Не добавляйте API-ключи в репозиторий. Тексты для эмбеддингов отправляются выбранному провайдеру: используйте сервис, которому разрешено передавать содержимое проекта.

## Инструменты MCP

| Инструмент | Назначение |
| --- | --- |
| `index_project` | Явно создать или обновить индекс связанной папки |
| `get_index_status` | Проверить состояние локального индекса |
| `search_semantic` | Найти фрагменты по смыслу запроса |
| `get_file_skeleton` | Получить структуру исходного файла внутри проекта |
| `find_usages` | Найти использования символа в локальном индексе |

После настройки попросите агента вызвать `index_project` и дождитесь завершения. Затем проверьте `get_index_status` и выполните пробный `search_semantic`, например «где проверяются параметры проекта». Пустой результат поиска и ошибка сервиса эмбеддингов отображаются как разные результаты.

Для совместного использования откройте вкладку «База знаний» проекта и отправьте индекс кнопкой «Синхронизировать с сервером». Скачивание серверной копии заменяет локальный индекс, поэтому сначала сохраните нужный локальный вариант.

## Ограничения и восстановление

- Автоматическая индексация, TUI upstream-плагина, описания изображений, decision-модель и reranking в этом MCP-комплекте не включены.
- Локальный индекс не подтверждён одной лишь установкой MCP. Его готовность и доступность провайдера проверяются отдельно; даже запрос состояния может потребовать доступной модели.
- Размерность модели должна совпадать с существующим индексом. При несовпадении адаптер отклоняет подключение. Верните исходную модель либо подготовьте отдельный индекс в отдельной копии проекта. Одинаковая размерность сама по себе не делает разные модели совместимыми.
- При отказе провайдера проверьте URL, протокол, имя модели и ключ в локальном мастере, затем повторите явную операцию. Не удаляйте прежний индекс для исправления сетевой ошибки.
- Готовый комплект для Intel Mac отсутствует из-за native-зависимости LanceDB выбранной версии. Каталог показывает поддерживаемые цели; другая архитектура не является заменой.

Состав адаптера и закреплённые версии описаны в `scripts/catalog-plugins/recipes/README.md` исходного репозитория Нейроцентра.
