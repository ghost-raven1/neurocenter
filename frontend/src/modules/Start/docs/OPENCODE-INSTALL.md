# Установка OpenCode с площадки Нейроцентра

## 1. Установите OpenCode

Скопируйте команду со страницы «Начало работы»: она уже содержит публичный адрес API Gateway вашей площадки.

macOS, Linux и WSL:

```sh
__INSTALL_POSIX__
```

Windows PowerShell:

```powershell
__INSTALL_WINDOWS__
```

В Git Bash подходит Bash-команда. Установщик выбирает пакет по ОС и архитектуре; архивы скачиваются с Нейроцентра. Глобальная установка OpenCode через npm не требуется. Существующая конфигурация и ключи сохраняются.

Предусмотрены пакеты для macOS Intel/Apple Silicon, Linux x64/ARM64 (glibc и musl), Windows x64/ARM64. WSL использует Linux-пакет. Наличие пакета на вашей площадке и совместимость с системой проверяются отдельно; перечень целей не подтверждает нативную приёмку каждой ОС.

После установки откройте новый терминал и проверьте:

```sh
opencode --version
```

Если пакет отсутствует, передайте администратору название архива из сообщения. Установщик не переключается на внешний registry.

### Локальный архив

Если администратор передал подходящий платформенный архив и сохранённый Bash-скрипт:

```sh
bash install_opencode.sh --binary ./opencode-package.tgz
```

Архив должен соответствовать системе компьютера. Скрипт проверяет запуск бинарника до замены действующей версии.

## 2. Подключите провайдер моделей

Выберите доступный вам провайдер и получите ключ, если он требуется. Запустите:

```sh
opencode auth login
```

Следуйте подсказкам выбранного провайдера. При необходимости отдельно укажите его URL и идентификаторы моделей в конфигурации OpenCode. Не добавляйте личные ключи в репозиторий. Наличие установленного бинарника не подтверждает доступность модели.

По умолчанию конфигурация находится в `~/.config/opencode`, авторизация — в `~/.local/share/opencode`. Переменные `XDG_CONFIG_HOME` и `XDG_DATA_HOME` учитываются. В Windows базовый каталог — домашняя папка пользователя. Подробности: [провайдеры OpenCode](https://opencode.ai/docs/providers/).

## 3. Подключите Нейроцентр

Перейдите к следующему шагу на странице «Начало работы» и установите мост. Он дополняет JSON/JSONC-конфигурацию, сохраняя другие MCP, плагины и комментарии.

Свяжите локальную папку с серверным проектом по постоянному ID. Названия папок и их расположение могут различаться на разных компьютерах. Не создавайте второй серверный проект только из-за другого локального пути.

Администратор проекта выбирает доступный набор инструментов, затем участник устанавливает разрешённые версии через мост в связанную папку. Кнопка «Установить через мост» у администратора также добавляет отсутствующий инструмент в каталог проекта. Простое добавление в каталог не запускает локальную установку.

## 4. Запустите из папки проекта

```sh
cd ~/projects/example-project
opencode
```

После добавления MCP или плагинов перезапустите OpenCode. LSP, семантический поиск и дополнительные плагины настраиваются отдельно.

Для OpenCodeRAG нужен доступный сервис эмбеддингов. Проектный хостинг локальной модели запускается командой `npm run embedding:up` из репозитория Нейроцентра; веса скачиваются отдельно. Новый плагин использует локальный адрес `http://127.0.0.1:11435/api` и модель `qwen3-embedding:4b`, сохраняя существующий `opencode-rag.json`. У отдельного MCP-адаптера провайдер задаётся в локальном мастере MCP. Подключение чат-модели в OpenCode не настраивает эмбеддинги автоматически.

OpenCode — отдельный публичный проект: [документация](https://opencode.ai/docs/).
