# opencode-snip: компактный вывод команд

[snip](https://github.com/edouard-claude/snip) фильтрует вывод команд перед передачей агенту. Нейроцентр поставляет `opencode-snip` 2.0.0 вместе с CLI snip 0.25.2 в одном платформенном комплекте. Степень сокращения зависит от команды и фильтра; фиксированный процент экономии не гарантируется.

## Установка через каталог

1. Подключите мост и свяжите папку `example-project` с серверным проектом.
2. Найдите opencode-snip в каталоге и установите разрешённую версию в выбранную папку.
3. Перезапустите OpenCode из этой папки.
4. При необходимости запустите отдельную диагностику плагина из списка установок.

Для этого комплекта не нужны ручное копирование инструкций, глобальная установка через npm или отдельное изменение PATH. CLI входит в поставку; адаптер обращается к нему по абсолютному пути. Диагностика запуска и фильтрация конкретной рабочей команды проверяются отдельно.

## Как работает адаптер

Перед выполнением инструмента `bash` плагин передаёт команду встроенному `snip hook`. Если hook предлагает изменённую команду, адаптер использует её. При ошибке hook или отсутствии изменения исходная команда сохраняется. Не все сложные shell-конструкции переписываются.

Сначала проверьте обычную команду, например `git status`. Если для диагностики нужен полный вывод, явно попросите агента выполнить команду без фильтрации.

## Ручная работа с CLI

Эти примеры относятся к отдельно доступной команде `snip`; наличие плагина в проекте не добавляет её в глобальный PATH.

| Команда | Назначение |
| --- | --- |
| `snip --version` | Проверить версию доступного CLI |
| `snip git status` | Выполнить команду через snip |
| `snip check -- git status` | Проверить выбор фильтра |
| `snip proxy -- git status` | Получить полный вывод без фильтрации |
| `snip gain` | Посмотреть локальную статистику |

Пользовательские YAML-фильтры и параметры CLI описаны в [документации snip](https://edouard-claude.github.io/snip/). Используйте синтаксис установленной версии. В проектных примерах называйте фильтры нейтрально, например `example-project-tsc`.

## Если результат не подходит

- После установки плагин не виден: перезапустите OpenCode и проверьте состояние установки в Нейроцентре.
- Команда выводится целиком: проверьте поддержку команды фильтром и правила переписывания hook. Это само по себе не означает ошибку запуска.
- Нужные строки скрыты: повторите команду с полным выводом и скорректируйте фильтр.
- Нужен откат: удалите установку через мост в выбранном проекте и перезапустите OpenCode.

Фильтр не меняет назначение исходной команды. Сетевая активность и изменения файлов зависят от выполняемой команды. Компактный результат не заменяет полный журнал при расследовании ошибки.

Комплект сохраняет лицензии upstream CLI и плагина. Публичные источники: [snip](https://github.com/edouard-claude/snip) и [пакет opencode-snip](https://www.npmjs.com/package/opencode-snip).
