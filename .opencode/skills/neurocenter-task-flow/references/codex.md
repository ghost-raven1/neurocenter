# Адаптер Codex

Применяй общую задачу через доступные в текущем клиенте средства. Если есть встроенное делегирование, передавай подагентам независимые подзадачи; для исследования/ревью используй общие роли. Установленные роли `neurocenter-explorer` и `neurocenter-reviewer` доступны в клиентах, поддерживающих их формат. При отсутствии пользовательских ролей передай соответствующий раздел `roles.md` обычному подагенту.

Подагенты текущей задачи не требуют новых пользовательских чатов. Отдельный чат создавай по просьбе пользователя. Следи за владельцами общих файлов и явно ожидай результат делегированной работы.

Перед продолжением поручения проверь состояние агента и семантику доступного API. Сообщение завершившему работу агенту может только попасть в очередь; используй средство повторного запуска (в текущем клиенте `followup_task`) и дождись подтверждённого результата. `send_message` подходит для координации уже работающего агента. Названия инструментов и их поведение сверяй с текущим клиентом.

Не считай инструкции механизмом изоляции: реальный доступ определяют инструменты и политика текущего клиента. Не переноси настройки Claude hooks в Codex и не меняй модели, MCP, sandbox или approvals автоматически ради этого workflow. Явный запрос пользователя на настройку MCP выполняй как отдельную ограниченную интеграцию: сохрани существующую конфигурацию, проверь транспорт, фактическое обнаружение и полезный вызов.

Для переноса после compaction используй короткий checkpoint задачи и текущий Git. Новые сообщения пользователя сначала применяй как уточнения, сохраняя исходную цель. Установка skill не заменяет уже загруженные инструкции активного чата; проверяй обнаружение в новой сессии.
