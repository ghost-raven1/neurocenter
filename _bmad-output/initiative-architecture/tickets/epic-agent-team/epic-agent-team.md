# Агент-команда end-to-end (C5)

## Description

Агент — участник проекта: роль, контекст, инструменты, публичные чаты (FR-301), системные роли (FR-303), проверяемый результат — верификация, а не «сделано» (FR-304). Реальный проект проведён агент-командой через BMAD → OpenSpec в основном рантайме (FR-308, закреплённые версии bmad-6.12.4 + openspec-1.15.0): фоновый агент в opencode-среде (FR-305), расширения только из каталога (FR-306), onboarding агента без оператора (FR-307), последовательный контекст и подключение агента агентом (FR-302), деление контекста с агентами/пользователем/командой (FR-309), вызов системного агента при проблеме/уточнении (FR-310); агенты работают в проектном чате эпика 8 (режимы FR-401, комнаты, семантический поиск FR-311).

## Outcome

Для команды: реальный проект закрыт агент-командой от анализа до подготовки выпуска с провенансом — следующий исполнитель получает принятые решения и исходные артефакты, а не пересказ (сигнал: PRD C5).

## Done when

1. Реальный проект проведён агент-командой end-to-end (анализ → требования → архитектура → задачи → код → тесты → ревью → подготовка выпуска) через BMAD → OpenSpec, закреплённые версии (FR-308).
2. Фоновый агент в opencode-среде: задача → работа в полной среде → результат в проектный чат (FR-305).
3. Расширения только из одобренного каталога (FR-306); экспериментальный режим — с записью в аудит.
4. Агент добавлен в проект без оператора; первая полезная операция — за минуты (FR-307).
5. Последовательный контекст: следующий агент видит опубликованные ответы предыдущих (FR-302).
6. Деление контекста: с агентами/пользователем/командой, с провенансом, только в комнаты с доступом (FR-309).
7. Вызов системного агента при проблеме/уточнении; recovery-путь при отсутствии пути продвижения (FR-310).
8. Результат — верификация (exit-code/покрытие), а не «сделано» (FR-304).
9. Пересказанные артефакты (без провенанса) = 0.

## Boundaries

- Проектный чат/комнаты/семантический поиск — эпик epic-project (этот эпик потребляет).
- mcp-host/билеты — эпик epic-trust-device-catalog.
- Устройство (FR-701) — вне мандата агент-команды: устройство = личный агент пользователя (FR-308).
