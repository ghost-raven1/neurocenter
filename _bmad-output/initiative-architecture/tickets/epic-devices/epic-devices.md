# Матрица установщиков (P0-NAT)

## Description

P0-NAT закрыт: установщики всех 8 клиентских целей (7 оставшихся) и полный чеклист для всех 8 (папки/настройки/восстановление/дочерние); устройство — личный opencode-агент пользователя, «одетый» проектом (FR-701), каждая установка — с квитанцией (FR-702); устройство работает offline (кэш) и переподключается без потери данных (FR-704); комплект декларирует поддерживаемые версии opencode, несовместимость — явная ошибка + следующий шаг (FR-706). UJ-3 работает как записан.

## Outcome

Для пользователя: новое устройство подключается к проекту за минуты без оператора (сигнал: PRD C1 P0-NAT, C2, UJ-3).

## Requirements

1. **R1 (FR-701, C2).** Устройство подключается установщиком по ОС как личный opencode-агент пользователя, «одетый» проектом: pairing, привязка папки, one-click установка комплекта проекта; пользователь работает без оператора. Свидетельство: установка за минуты на каждой из 8 целей (чеклист, пункт 1) и работающее подключённое устройство.
2. **R2 (FR-702).** Каждая установка (install/update/restore) оставляет проверяемую квитанцию; повтор idempotent — существующий JSON/JSONC, комментарии, другие MCP-конфигурации и привязки папок не дублируются. Свидетельство: квитанция в отчёте; второй запуск ничего не дублирует (чеклист, пункт 2).
3. **R3 (FR-704).** Устройство работает offline (кэш) и переподключается без потери данных: настройки, привязки папок и учётные данные переживают отключение, restart и обновление. Свидетельство: восстановление привязок после restart и обновление с сохранением (чеклист, пункты 3–4).
4. **R4 (FR-706, NFR-3).** Комплект проекта декларирует поддерживаемые версии opencode (единый источник); мост определяет фактическую версию на устройстве; несовместимая версия — без тихой установки: явная ошибка + actionable следующий шаг (обновить / совместимая версия). Свидетельство: версия вне диапазона → явная ошибка со следующим шагом; версия в диапазоне → установка.
5. **R5 (P0-NAT).** Для каждой из 8 целей — darwin-arm64, darwin-x64, linux-arm64, linux-arm64-musl, linux-x64, linux-x64-musl, windows-arm64, windows-x64 — пройден полный 8-пунктный native-чеклист с отдельным отчётом, привязанным к единому точному кандидату (архив + build ID + SHA): явные `native:true` и `OS security unchanged:true`, журналы без секретов. Свидетельство: 8 отдельных полных отчётов; `allEightAccepted` возможно только при 8/8.
6. **R6 (UJ-3, родитель R12).** Полезный MCP-вызов с нового устройства работает как записан (UJ-3: квитанция, повтор idempotent, полезный MCP-вызов). Свидетельство: сценарий от чистой установки до успешного вызова инструмента проекта.

## Constraints

1. **C1 (P0-NAT).** Нативная приёмка выполняется на целевой ОС/архитектуре/libc с Node.js 24; Linux-цели — на машинах с графической сессией (readiness); подмена uname/ldd, cross-build, контейнер другой архитектуры и синтетический PE не являются нативной приёмкой.
2. **C2 (P0-NAT).** Windows: реальный job-helper нужной архитектуры и штатная политика ОС — установка доверенного скрипта без постоянного bypass; install.ps1 проверяется нативным PowerShell-runner на изолированном профиле с отдельными журналами; отсутствие runner/подписи нельзя выдавать за успешную автоматическую приёмку.
3. **C3 (P0-NAT).** Все 8 отчётов — к единому точному кандидату (архив + build ID + SHA); старые частичные/фикстурные результаты (включая darwin-arm64 0.9.3/0.9.4) не суммируются с новым прогоном; исторические матрицы не изменяются — новый кандидат получает отдельный отчёт.
4. **C4 (P0-NAT).** На darwin-x64 локальная RAG сейчас unsupported — ограничение записывается явно в отчёте цели, а не обходится.
5. **C5 (P0-NAT).** Имена целей матрицы моста не смешиваются с контрактами runtime-assets (`win32-*`, `linux-*-glibc`): это два контракта; evidence сохраняет исходный target дескриптора и явно указывает строку матрицы.

## Done when

1. Установщики всех 8 клиентских целей (7 оставшихся).
2. Полный чеклист для всех 8: папки/настройки/восстановление/дочерние.
3. Каждая установка — с квитанцией (FR-702); повтор idempotent.
4. Устройство работает offline (кэш) и переподключается без потери данных (FR-704).
5. Несовместимая версия opencode — явная ошибка + следующий шаг (FR-706).
6. Полезный MCP-вызов с нового устройства (UJ-3).
