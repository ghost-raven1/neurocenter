# Spec Delta

## Purpose

Связать выбранного проектного агента с полным циклом методики, реальным локальным исполнением и сохранёнными доказательствами результата.

## ADDED Requirements

### Requirement: Explicit project agent execution
Система SHALL запускать выбранного включённого проектного агента с закреплённым профилем и явной моделью в точной папке проекта. При невозможности такого запуска MUST отсутствовать подмена исполнителя или модели значениями по умолчанию.

#### Scenario: Run the selected agent
- **WHEN** администратор выбирает готового агента и отправляет задачу BMAD/OpenSpec
- **THEN** фактический runtime использует его native имя и модель, а результат указывает исходного исполнителя

#### Scenario: Ineligible selection
- **WHEN** агент выключен, удалён, архивирован, не имеет явной модели или поддержанного режима исполнения
- **THEN** новый запуск отклоняется с доступным продолжением без потери текста задачи

### Requirement: Pinned configuration freshness
Принятый запрос SHALL фиксировать идентичность назначения, его ревизию, доказанную доставку и хеш native-файла. Перед dispatch и принятием результата MUST проверяться актуальность серверного и локального профиля, модели и привязки.

#### Scenario: Assignment changes while queued
- **WHEN** профиль, модель или ревизия назначения меняется после принятия задания
- **THEN** старое задание не начинает исполнение с новым профилем

#### Scenario: Native file or model changes
- **WHEN** локальный native-файл, namespace либо соответствие модели отличается от принятого снимка
- **THEN** выполнение останавливается и требует настройки, сохраняя уже наблюдённые факты

### Requirement: Durable selected-agent recovery
Система SHALL сохранять выбор агента в точном запросе и квитанции. Восстановление после неизвестного ACK MUST возвращать прежний результат без нового исполнения. История и отмена MUST оставаться доступны при OFF в пределах действующих прав.

#### Scenario: Lost selected-agent acknowledgement
- **WHEN** ответ на отправку или completion теряется
- **THEN** восстановление сохраняет того же агента и ключ, не выбирает первого доступного и не повторяет принятый runtime

#### Scenario: Disabled feature and legacy history
- **WHEN** новая функция отключена
- **THEN** выбранный агент не получает новый запуск, прежние квитанции читаются и отменяются; старые задания без выбора агента сохраняют совместимый путь

### Requirement: Honest readiness and result
Интерфейс SHALL показывать выбранного исполнителя, методику, целевую папку и реальные исходы проверок. Отсутствие подтверждённой настройки MUST давать причину и следующее действие без ложного успеха или автоматического переключения агента.

#### Scenario: Configuration not delivered
- **WHEN** нет актуальной успешной доставки профиля в выбранную папку
- **THEN** пользователь получает предложение применить настройку агентов или настроить модель, сохраняя задачу
