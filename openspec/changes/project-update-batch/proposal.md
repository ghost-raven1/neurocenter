# Proposal

## Why

Когда в разных проектах закреплена старая редакция, а в общем каталоге вышла новая, администратору приходится открывать каталог каждого проекта, находить карточку и по отдельности закреплять новую версию. Запрошено: увидеть все такие проекты в одном месте, закрепить точные редакции одним подтверждением и видеть живые статусы установки — не «ходить кругами».

## What Changes

- Новая вкладка «Обновления проектов» в общем каталоге (флаг `project_update_batch`, group `catalog`, зависит от `project_update_apply`, default on): все проекты, где пользователь управляет каталогом (роль ≥ 3), и назначения, чья закреплённая редакция старше общего каталога.
- Массовое закрепление: подтверждение с таблицей точных версий (проект | инструмент | текущая → новая) и последовательный pin с CAS per-project (expectedVersion/expectedManifest из строки проекта). Параллельное изменение пина (409) помечается по строке, батч не останавливается; после батча каталоги перечитываются.
- Живые статусы установки: задания моста глобальны (job.projectId), поэтому статус «в очереди / устанавливается / установлено / сбой» показывается без чтения каталога проекта.
- Установка новой редакции по-прежнему одобряется в каталоге каждого проекта: кнопка «Открыть проект» переводит в каталог проекта, где план установки подтверждается как прежде. Явные подтверждения (CAS, план, danger-модалки) не отрезаются.
- Flag off: вкладка не существует, запросы каталогов не идут, прямой URL `?tab=updates` возвращается на «Инструменты» (поведение до флага).

## Capabilities

### New Capabilities

- `project-update-batch`: кросс-проектный обзор обновлений, батч-закрепление точных редакций и живые статусы установки.

### Modified Capabilities

Нет. Переиспользуются существующие API каталогов проектов (`GET /api/projects/:id/catalog`), пинирования (`PATCH /api/projects/:id/assets/pin`) и задания моста.

## Impact

Store (новая вкладка, презентационный компонент, чистый хелпер, хук чтения каталогов набора проектов, стили), каталог флагов (JSON + union), тесты. Установка и одобрение планов не изменяются; в проектном каталоге (embedded) вкладка отсутствует.
