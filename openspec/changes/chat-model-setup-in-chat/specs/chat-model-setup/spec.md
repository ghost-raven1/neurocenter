# Spec Delta

## Purpose

Позволяет довести модель выбранного проекта до готовности для чата прямо в окне чата, показывая пробел и действие по каждой модели без перехода в каталог.

## ADDED Requirements

### Requirement: Панель настройки модели в чате
Система SHALL показывать панель «Модель для чата» в окне личных диалогов, когда выбран проект, у пользователя рабочая роль, каталог прочитан, флаг `chat_model_setup` включён, и ни одна модель не готова для чата. Панель MUST перечислять модели, доступные в выборе модели этого контекста (в том же объёме, что и селектор чата; без embedding и archived), с причиной и доступными действиями.

#### Scenario: Нет готовой модели
- **WHEN** в выбранном проекте есть модели, но ни одна не готова для чата
- **THEN** вместо пустого состояния показывается панель, где у каждой модели видна причина (назначение, провайдер и ключ, проверка) и соответствующее inline-действие.

#### Scenario: Есть готовая модель
- **WHEN** хотя бы одна модель готова для чата в выбранном проекте
- **THEN** панель не показывается, выбор модели и сохранённые диалоги доступны как прежде.

#### Scenario: Роль не может назначать
- **WHEN** модель не добавлена в проект, а роль пользователя ниже уровня управления проектом
- **THEN** действие «Добавить в проект» не предлагается и показывается, что добавить модель может администратор проекта.

#### Scenario: Пустой каталог
- **WHEN** в каталоге нет моделей для чата
- **THEN** панель объясняет это и указывает на кнопку «Подключить модель» без пустых строк действий.

#### Scenario: Флаг выключен
- **WHEN** флаг `chat_model_setup` выключен
- **THEN** панель не показывается; сохраняется прежний текст пустого состояния и переход в каталог.

### Requirement: Закрытие пробелов без ухода из чата
Система SHALL выполнять действия готовности существующими владельцами: назначение модели проекту (роль не ниже уровня управления), настройка провайдера и личного ключа (общий адрес — только главный администратор, личный ключ — «Мой доступ») и проверка подключения модели. После каждого успешного действия каталог MUST перечитываться.

#### Scenario: Добавление модели в проект
- **WHEN** пользователь с правом управления нажимает «Добавить в проект»
- **THEN** модель назначается действующим API назначения, каталог перечитывается, и при готовности модель сразу появляется в выборке чата.

#### Scenario: Провайдер и ключ для главного администратора
- **WHEN** главный администратор нажимает «Настроить провайдера и ключ»
- **THEN** открывается модалка доступа: общий адрес и настройки меняются через модалку подключения с подтверждением ревизии, а после сохранения открывается шаг личного ключа с уведомлением; каталог перечитывается.

#### Scenario: Личный ключ без права на адрес
- **WHEN** пользователь, не являющийся главным администратором, нажимает «Настроить провайдера и ключ»
- **THEN** общий адрес остаётся неизменным (настраивает главный администратор), а личный ключ доступен через «Мой доступ».

#### Scenario: Проверка подключения
- **WHEN** главный администратор нажимает «Проверить подключение»
- **THEN** выполняется проверка модели действующим hosting-оператором, панель дожидается завершения операции и после этого перечитывает каталог; для роли без права управления хостингом действие не предлагается и показывается, что проверку выполняет главный администратор.

#### Scenario: Отказ действия
- **WHEN** назначение, сохранение провайдера или проверка завершились ошибкой
- **THEN** ошибка показывается в панели, состояние модели не подменяется готовностью, и доступен повтор.

### Requirement: Выход в каталог сохраняется
Система SHALL сохранять кнопку «Подключить модель» и полный сценарий каталога параллельно панели: панель не заменяет создание моделей и управление каталогом.

#### Scenario: Создание новой модели
- **WHEN** пользователю нужна модель, которой нет в каталоге
- **THEN** кнопка «Подключить модель» открывает каталог с выбранным проектом, и создание модели проходит прежним сценарием.

#### Scenario: История и повторное открытие
- **WHEN** пользователь закрыл панель или окно чата и открыл диалог заново
- **THEN** сохранённые диалоги, выбор проекта и моделей восстанавливаются; панель появляется только при отсутствии готовой модели.
