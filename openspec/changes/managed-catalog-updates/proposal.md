# Proposal

## Why

Пользователь не видит предложений обновления MCP, плагинов и агентов, а действующая поставка OpenCodeRAG остаётся на 2.4.4. Обновление исходников Нейроцентра должно приносить проверенный текущий каталог без обязательного отдельного asset-репозитория или GitHub Releases.

## What Changes

- Каталог проекта показывает новые редакции общих шаблонов и отдельно различия между закреплением проекта и квитанцией выбранной папки; фильтр обновлений сохраняет ожидание, ошибки и восстановление.
- Подтверждение новой версии использует существующие CAS, план установки и выбранный локальный мост. Ручная конфигурация, переопределения агентов и прежняя установка сохраняются при отказе.
- Рецепты MCP и плагина OpenCodeRAG переходят на точные npm/Git байты 2.12.2 с проверенной совместимостью управляемой фабрики с закреплённым OpenCode. Проверяются полный Quirk JSONL, размерность, неполное индексирование и обновление конфигурации во время сессии.
- Текущие немодельные описания, исходники и dependency locks входят в основной Git. Исторические квитанции читаются по прежним точным SHA; старые runtime-архивы и автоматическая загрузка весов не входят в обычную поставку.
- По уточнению 30.10 пересборка основного режима готовит текущий мост и запускает фактическую подготовку/публикацию встроенных немодельных пакетов через действующие очереди. Обновление только source metadata не считается обновлением каталожного пакета. Ручные карточки, проектные закрепления и установленные файлы не заменяются этим действием.

## Capabilities

### New Capabilities

- `catalog-update-proposals`: заметные, привязанные к проекту и папке предложения с явным продолжением через действующий мост.
- `managed-rag-runtime`: проверяемая совместимость текущего OpenCodeRAG, безопасная конфигурация и сохранность индекса/Quirk-источника.
- `bundled-catalog-supply`: текущий каталог из основного Git с точным происхождением и читаемой историей.

### Modified Capabilities

Основных specs ещё нет. Сохраняются принятые границы `asset-independent-deployment`, `role-chats-and-agent-methods` и `unified-project-setup`; базовое развёртывание, агрегатор знаний и мастер настройки здесь не перепроектируются.

## Impact

Store/AgentCatalog и существующие флаги `tool_catalog`, `tool_installation`, `agents`; RAG recipes, dependency locks, shared Quirk contract и retained source closure; источник описаний Catalog и asset CLI. Изменений схем БД и автоматического обновления пользовательских конфигураций не требуется. Удаление прежнего asset-репозитория, сервер пользователя, CI и другие ОС принимаются отдельно после проверенной миграции.
