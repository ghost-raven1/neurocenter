# Spec Delta

## Purpose

Позволяет устанавливать и обновлять Нейроцентр с текущим немодельным каталогом из одного основного репозитория, сохраняя проверяемое происхождение и старые квитанции.

## ADDED Requirements

### Requirement: Current source accompanies application Git
Система SHALL получать текущие немодельные описания, исходники, рецепты и точные dependency locks вместе с основным Git. Запуск не требует доступа к прежнему asset-репозиторию или GitHub Releases; неподготовленный optional runtime имеет явное состояние и путь подготовки.

#### Scenario: Недоступно прежнее хранилище
- **WHEN** новый собственный checkout не имеет blob-кэша, прежний asset-репозиторий и GitHub Releases недоступны, а обычный npm разрешён
- **THEN** базовый запуск и текущие описания немодельного каталога доступны; подготовка выбранного компонента использует проверенные локальные исходники и точные обычные зависимости

### Requirement: Immutable history and stable identity
Система SHALL сохранять прежние descriptor SHA, native ID, project pins, квитанции и историю; пересборка с иными байтами создаёт новую immutable версию. Новая текущая поставка не перезаписывает пользовательские карточки, forks, конфигурацию или активные задания.

#### Scenario: Старое закрепление и изменённая карточка
- **WHEN** сервер содержит старое закрепление, прежнюю квитанцию и пользовательское изменение общего инструмента
- **THEN** история остаётся читаемой, импорт новой текущей версии требует действующего явного разрешения конфликта и не создаёт дубликат стабильного инструмента

### Requirement: No implicit model weight delivery
Система SHALL доставлять веса hosting-моделей только по явному импорту GGUF/архива. Git pull, post-pull, install, up, full, синхронизация и восстановление прошлых выборов могут читать metadata, но не загружать веса автоматически.

#### Scenario: Сохранён прежний выбор модели
- **WHEN** обычное обновление выполняется с прежним сохранённым model ID
- **THEN** веса не скачиваются; интерфейс предлагает разрешённый явный импорт и не показывает отсутствующий runtime готовым

### Requirement: Verified local preparation preserves previous generation
Система SHALL проверять источник, lock, target, SHA и фактический комплект до активации. Отмена, повтор, нехватка файлов или отказ optional builder сохраняют предыдущую рабочую generation и дают явное продолжение.

#### Scenario: Несовместимый локальный архив
- **WHEN** пользователь выбирает архив с иной target либо несовпадающей SHA
- **THEN** компонент не активируется, прежние настройки и generation сохраняются; остальные готовые немодельные компоненты остаются доступны
