# Proposal

## Why

На `/start` OpenCode, мост, папка, агенты и инструменты настраиваются раздельно с переходами между страницами. Пользователь просит одну точку входа «Установить OpenCode», которая доводит выбранный проект до проверенного окружения и позволяет продолжить после частичного отказа.

## What Changes

- Основная кнопка открывает единый проектный мастер: общий установщик OpenCode и моста, подключение, выбор проекта и папки, агенты и назначенные инструменты, проверка состояния.
- Общий bootstrap последовательно запускает существующие установщики с той же площадки; ошибка первого шага останавливает следующий, а отказ моста позволяет повторить только его установку.
- Настройка папки, модели, агентов и ассетов использует действующие owners, планы, одобрения, версии и ключи запросов без скрытого скачивания всего каталога.
- Статус отражает текущие отчёты выбранного компьютера и папки. Копирование команды или успешное скачивание не считаются установленным и проверенным окружением.
- Новая точка входа управляется флагом; прежние ссылки, история и восстановление сохраняются.

## Capabilities

### New Capabilities

- `unified-project-setup`: одна точка входа и продолжаемый мастер установки OpenCode, моста и окружения выбранного проекта.

### Modified Capabilities

Нет. Переиспользуются существующие установщики, plans и конфигурационные мастера.

## Impact

Start, узкие UI adapters существующих мастеров, connectionCommands, два новых bootstrap scripts и Gateway endpoints, каталог флагов, справка и проверки. Новый универсальный installer backend/очередь не требуется. Модель/учётные данные выбираются явно в локальном мастере; ручная конфигурация сохраняется владельцами установки.
