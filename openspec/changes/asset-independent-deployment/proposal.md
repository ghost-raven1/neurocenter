# Proposal

## Why

Недоступность внешнего хранилища ассетов и сборки проверщика снимков сейчас блокирует базовое развёртывание. Пользователю нужен работающий Нейроцентр с полезной базой знаний из коробки и возможностью позже добавить необходимые компоненты из проверенного архива.

## What Changes

- Существующий базовый профиль запускается без предзагрузки ассетов, упаковки Native и обязательного контейнера проверщика. Основные Node-сервисы и PostgreSQL сохраняются.
- Небольшой контракт ассетов входит в исходную поставку с закреплённым происхождением; холодная установка не получает его из недоступного asset-репозитория.
- Ассеты добавляются через действующий UI архивного импорта: проверенная metadata-опись и файлы выбранных компонентов, без обязательной загрузки всех моделей. Права, immutable история и проверки SHA сохраняются.
- Неподготовленный проверщик запрещает новые публикации снимков с понятным продолжением, сохраняя ключи, историю, отмену и восстановление.
- Базовая база знаний получает загрузку текстовых документов и поиск цитат в существующем PostgreSQL без embedding-модели, плагина и дополнительных сторонних runtime-зависимостей. Текстовый контекст становится доступен явно выбранному чату/агенту; платные вызовы автоматически не выполняются.
- Существующий семантический индекс, выбранная модель, размерность, reindex и повреждённое локальное Quirk-хранилище сохраняются у прежних владельцев.

## Capabilities

### New Capabilities

- `core-deployment`: базовая установка и запуск независимо от внешнего хранилища ассетов и опциональных исполнителей.
- `archive-component-delivery`: добавление выбранных компонентов из доверенной архивной поставки через UI.
- `basic-project-knowledge`: работающий текстовый корпус проекта, поиск источников и их использование без embedding-инфраструктуры.

### Modified Capabilities

Опубликованных основных specs пока нет. Существующие изменения `bridge-first-local-setup` и `role-chats-and-agent-methods` остаются связанными контрактами; новый порядок клиентского мастера не переопределяется.

## Impact

Dev CLI и dependency manifests/locks, Docker-копирование небольшого контракта, readiness проверщика снимков, архивный импорт Catalog и его UI-проверки, RAG/Catalog/Gateway и база знаний проекта. Новое текстовое поведение управляется независимым флагом; доступ проверяется отдельно. Полная автономность npm/ОС, обновление upstream OpenCodeRAG и неподписанные произвольные архивы в этот срез не входят.
