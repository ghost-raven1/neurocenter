# Spec Delta

## Purpose

Позволяет после базового развёртывания добавлять нужные компоненты из доверенного архива через интерфейс без доступа площадки к внешнему хранилищу ассетов.

## ADDED Requirements

### Requirement: Selective archive delivery
Система SHALL принимать через UI доверенную metadata-опись и файлы выбранных компонентов, проверять SHA, пути, размеры, зависимости и совместимость. Отсутствие файлов невыбранных моделей MUST NOT блокировать готовые компоненты.

#### Scenario: Import selected tool without model weights
- **WHEN** администратор загружает архив закреплённого источника с полной metadata-историей и необходимыми файлами выбранного инструмента, но без весов других моделей
- **THEN** инструмент доступен для явного импорта без внешних загрузок, а отсутствующие модели показаны недоступными

#### Scenario: Existing trusted source and assignments
- **WHEN** подтверждён импорт новой поставки выбранного компонента
- **THEN** сохраняются stable ID, immutable история, пользовательские карточки, прежние назначения и настройки; назначения меняются отдельным явным действием

### Requirement: Failure preserves accepted state
Система SHALL сохранять принятый каталог при отказе SHA, недоверенном источнике, отмене, отзыве прав и потере подтверждения. Повтор одного запроса MUST восстанавливать тот же результат, а не создавать другую поставку.

#### Scenario: Invalid or incomplete component
- **WHEN** архив повреждён либо для выбранного компонента отсутствует обязательный файл
- **THEN** импорт этого компонента не меняет каталог, причина и путь продолжения доступны в UI

#### Scenario: Rights revoked before import
- **WHEN** права пользователя отозваны после загрузки архива до первой мутации каталога
- **THEN** операция отклоняется по свежим правам, принятые карточки и назначения сохраняются

#### Scenario: No hidden network fallback
- **WHEN** импортируется принятый архив при недоступных asset-hosts
- **THEN** файлы используются только из локально проверенного кэша; отсутствующие bytes не запускают скрытую сетевую догрузку
