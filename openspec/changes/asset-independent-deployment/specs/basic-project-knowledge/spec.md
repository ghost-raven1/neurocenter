# Spec Delta

## Purpose

Делает базу знаний нового проекта полезной без предварительной установки плагина, embedding-модели или внешней RAG-инфраструктуры: тексты, поиск источников и контекст выбранного чата.

## ADDED Requirements

### Requirement: Basic project text corpus
Система SHALL позволять через UI добавлять обычные текстовые документы и искать в них цитаты в пределах проекта без embedding-вызовов и новых сторонних runtime-зависимостей. Готовность текстов MUST отличаться от готовности семантического индекса.

#### Scenario: First useful search
- **WHEN** пользователь нового проекта добавляет русский текст или исходный код и выполняет поиск при пустом asset-кэше и отсутствии embedding-модели
- **THEN** интерфейс показывает соответствующие цитаты с источниками и явным текстовым режимом; внешних модельных вызовов нет

#### Scenario: Empty or unmatched corpus
- **WHEN** документов нет либо запрос не находит совпадений
- **THEN** показано корректное пустое состояние с действием добавления документов, вымышленные цитаты не возвращаются

### Requirement: Project authority and atomic text revision
Система MUST проверять актуальные права проекта перед записью и чтением, применять квоту атомарно и связывать повтор запроса с теми же байтами. Поиск SHALL возвращать согласованную ревизию корпуса.

#### Scenario: Lost acknowledgement and concurrent search
- **WHEN** подтверждение загрузки потеряно и пользователь повторяет запрос во время поиска
- **THEN** возвращается прежняя квитанция, документы не дублируются, поиск видит целую старую либо новую ревизию

#### Scenario: Quota or permission failure
- **WHEN** превышен бюджет проекта либо отозваны права перед мутацией
- **THEN** загрузка отклоняется целиком, прежние документы и ревизия сохраняются, интерфейс сохраняет ввод и предлагает продолжение

### Requirement: Grounded context without changing semantic state
Система SHALL включать выбранные текстовые источники и их ревизию в явно запрошенный контекст чата или агента. Новая функция MUST иметь независимый флаг без зависимости от model hosting и сохранять прежний semantic-профиль, размерность и поколения.

#### Scenario: Chat uses the selected text corpus
- **WHEN** пользователь явно отправляет запрос с текстовой базой знаний проекта
- **THEN** принятый контекст содержит ограниченные цитаты и идентичность ревизии, а отсутствие embedding-модели не мешает retrieval

#### Scenario: Existing semantic index and damaged local storage
- **WHEN** проект уже имеет выбранную модель, semantic generation или повреждённый локальный Quirk
- **THEN** текстовая загрузка не изменяет их, не создаёт фиктивные векторы и не удаляет локальный baseline

#### Scenario: Feature off
- **WHEN** новый текстовый режим выключен
- **THEN** новые текстовые операции недоступны, принятая история, квитанции и восстановление сохраняются с обычной авторизацией
